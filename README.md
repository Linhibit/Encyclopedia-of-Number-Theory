### 1. **求最大公约数——欧几里得算法**

快速计算两个整数的最大公约数 (GCD)：

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

# 示例:
print(gcd(48, 18))  # 结果: 6
```

### 2. **素数筛选法（埃拉托色尼筛法）**

生成一个范围内的所有素数：

```python
def sieve_of_eratosthenes(n):
    primes = [True] * (n + 1)
    p = 2
    while (p * p <= n):
        if primes[p]:
            for i in range(p * p, n + 1, p):
                primes[i] = False
        p += 1
```
