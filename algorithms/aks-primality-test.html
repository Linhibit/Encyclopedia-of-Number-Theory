AKS素性测试 (Agrawal–Kayal–Saxena Primality Test)

算法原理：

AKS素性测试是第一个被发表的、一般的、多项式的、确定性的和无依赖的素数判定算法[citation:3][citation:5]。它由印度坎普尔理工学院的Manindra Agrawal、Neeraj Kayal和Nitin Saxena于2002年提出，解决了几个世纪以来的开放问题——素数判定是否属于P，并因此获得了2006年的哥德尔奖和Fulkerson奖[citation:3]。

核心定理： 整数 $n \geq 2$ 是素数，当且仅当对于所有与 $n$ 互素的整数 $a$，有： $$(X + a)^n \equiv X^n + a \pmod{n}$$ 这是费马小定理在多项式环上的推广[citation:3][citation:10]。AKS算法通过选取合适的参数 $r$ 并限制 $a$ 的范围，在多项式时间内检验该同余式。

历史意义： 先前的算法至多达到以下三点之一，但从未达到全部四个：

  • 一般性：适用于所有整数，而非特定形式的数（如梅森数、费马数）[citation:3]
  • 多项式时间：运行时间是输入规模 $\log n$ 的多项式函数[citation:5]
  • 确定性：总是给出正确结果，而非概率性[citation:3]
  • 无依赖：不依赖任何未证明的猜想（如广义黎曼猜想）[citation:3]

算法步骤：

  1. 输入： 整数 $n > 1$。
  2. 检测完全幂： 如果 $n = a^b$，其中 $a \in \mathbb{N}$，$b > 1$，则输出"合数"[citation:8][citation:10]。
  3. 寻找最小的 $r$： 找到最小的 $r \in \mathbb{N}$，使得 $\operatorname{ord}_r(n) > \log^2 n$（即 $n^k \not\equiv 1 \pmod{r}$ 对所有 $k \leq \log^2 n$ 成立）[citation:8][citation:10]。
  4. 检查小因子： 如果存在 $a \leq r$ 使得 $1 < \gcd(a, n) < n$，则输出"合数"[citation:8][citation:10]。
  5. 小 $n$ 特判： 如果 $n \leq r$，则输出"素数"[citation:8][citation:10]。
  6. 核心多项式检验： 对于 $a = 1$ 到 $\lfloor \sqrt{\phi(r)} \log n \rfloor$：
    检验多项式同余式是否成立： $$(X + a)^n \equiv X^n + a \pmod{X^r - 1, n}$$ 如果不成立，输出"合数"[citation:8][citation:10]。
  7. 输出： "素数"[citation:8]。
复杂度分析：
  • 原始AKS算法的时间复杂度为 $O((\log n)^{12})$[citation:2][citation:5]。
  • 后续改进版本（如Bernstein的改进）将复杂度降至 $O((\log n)^6)$[citation:1][citation:6]。
  • 尽管是多项式时间，但实际运行速度远慢于概率算法（如Miller-Rabin），因此主要用于理论意义[citation:10]。

示例：

示例1： 测试 $n = 31$（素数）。

过程：

  1. $31$ 不是完全幂（如 $5^2=25$, $6^2=36$）
  2. 寻找 $r$：需要 $\operatorname{ord}_r(31) > \log^2 31 \approx 5^2=25$。
    • 尝试 $r=29$：$31 \bmod 29 = 2$，$2^1,2^2,...,2^{28}$ 中最小使 $2^k \equiv 1 \pmod{29}$ 的 $k=28$，大于25，符合条件。
  3. 检查 $a \leq 29$ 的 $\gcd(a,31)$，均为1（因为31是素数），通过。
  4. $n=31 > r=29$，继续核心检验。
  5. 对于 $a=1$ 到 $\lfloor \sqrt{\phi(29)} \log 31 \rfloor = \lfloor \sqrt{28} \times 5 \rfloor \approx 26$，检验多项式同余式。由于31是素数，所有同余式成立[citation:10]。
  6. 输出"素数"。

示例2： 测试 $n = 35$（合数）。

过程：

  1. $35$ 不是完全幂（$5^2=25$, $6^2=36$）
  2. 寻找 $r$：需要 $\operatorname{ord}_r(35) > \log^2 35 \approx 5.13^2 \approx 26.3$。
    • 尝试 $r=29$：$35 \bmod 29 = 6$，$6^1,6^2,...$ 中 $6^{14} \equiv 1 \pmod{29}$，14 < 26.3，不符合。
    • 尝试 $r=31$：$35 \bmod 31 = 4$，$4^{15} \equiv 1 \pmod{31}$，15 < 26.3，不符合。
    • 继续增加 $r$，但实际会在第4步检测出小因子：对于 $a=5 \leq r$，$\gcd(5,35)=5$，且 $5 \neq 1$ 且 $5 \neq 35$，在第4步输出"合数"。
  3. 输出"合数"。

示例3： 小 $n$ 特判。

对于 $n=3$，在第2步后找到的 $r$ 可能大于3，此时 $n \leq r$，算法直接在第5步输出"素数"[citation:8][citation:10]。

代码示例 (Python)：

注：这是一个教学性质的简化实现，完整的高效实现需要复杂的多项式运算优化[citation:1][citation:6]。

import math

def is_perfect_power(n):
    """检查n是否为某个整数的幂（指数>1）"""
    for b in range(2, int(math.log2(n)) + 1):
        a = round(n ** (1 / b))
        if a ** b == n:
            return True
    return False

def poly_mod_mul(p1, p2, mod, r):
    """多项式乘法模 (X^r - 1, mod)"""
    res = [0] * (2 * r)
    for i in range(len(p1)):
        for j in range(len(p2)):
            res[i + j] = (res[i + j] + p1[i] * p2[j]) % mod
    # 模 X^r - 1 化简
    for i in range(2 * r - 1, r - 1, -1):
        res[i - r] = (res[i - r] + res[i]) % mod
    return res[:r]

def poly_mod_pow(poly, exp, mod, r):
    """多项式快速幂模 (X^r - 1, mod)"""
    result = [1] + [0] * (r - 1)
    base = poly[:]
    while exp > 0:
        if exp & 1:
            result = poly_mod_mul(result, base, mod, r)
        base = poly_mod_mul(base, base, mod, r)
        exp >>= 1
    return result

def aks_primality_test(n):
    """AKS素性测试"""
    if n <= 1:
        return False
    if n <= 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    
    # 第1步：检测完全幂
    if is_perfect_power(n):
        return False
    
    # 第2步：寻找最小的r，使得 ord_r(n) > log^2 n
    log_n = math.log2(n)
    log2_n = int(log_n * log_n)  # 近似 log^2 n
    
    r = 2
    while True:
        if math.gcd(r, n) != 1:
            r += 1
            continue
        # 检查 n^k mod r 是否为1
        found = True
        for k in range(1, log2_n + 1):
            if pow(n, k, r) == 1:
                found = False
                break
        if found:
            break
        r += 1
    
    # 第3步：检查小因子
    for a in range(2, min(r, n)):
        g = math.gcd(a, n)
        if 1 < g < n:
            return False
    
    # 第4步：如果 n <= r，则n是素数
    if n <= r:
        return True
    
    # 第5步：核心多项式检验
    max_a = int(math.sqrt(r - 1) * log_n)  # φ(r) ≤ r-1
    # 构建多项式 (X + a)
    for a in range(1, max_a + 1):
        # 计算 (X + a)^n 模 (X^r - 1, n)
        poly_base = [a % n, 1] + [0] * (r - 2)  # X + a
        poly_exp = poly_mod_pow(poly_base, n, n, r)
        
        # 期望结果 X^n + a 模 (X^r - 1, n)
        expected = [0] * r
        expected[0] = a % n  # 常数项 a
        expected[n % r] = (expected[n % r] + 1) % n  # X^(n mod r)
        
        if poly_exp != expected:
            return False
    
    return True

# 示例测试
print("=== AKS素性测试示例 ===")
test_numbers = [2, 3, 17, 19, 23, 27, 29, 31, 35, 37, 41, 49]
for n in test_numbers:
    result = aks_primality_test(n)
    print(f"{n}: {'素数' if result else '合数'}")

print("\n=== 性能测试（小范围）===")
for n in [97, 101, 103, 107, 109, 113, 121]:
    print(f"测试 {n}...")
    result = aks_primality_test(n)
    print(f"{n}: {'素数' if result else '合数'}")
    print("-" * 30)

应用与意义：

  1. 理论计算机科学： AKS算法解决了"素数是否属于P"这一重要复杂性理论问题，是计算复杂性理论的里程碑[citation:3]。
  2. 数论研究： 提供了第一个无条件确定性多项式时间素数判定算法，对数论研究具有深远影响[citation:5]。
  3. 密码学基础： 虽然实际密码学中更常用Miller-Rabin等概率算法，但AKS的存在保证了素数判定的理论可行性[citation:1]。
  4. 算法改进与优化： 后续出现了众多改进版本（如Bernstein的优化），将复杂度降至 $O((\log n)^6)$，并在小范围内实现了实用化[citation:6][citation:9]。

与其它素数测试的比较：

算法 类型 时间复杂度 优点 缺点
试除法 确定性 $O(\sqrt{n})$ 简单，绝对正确 对大数不可行
Miller-Rabin 概率性 $O(k \log^3 n)$ 极快，广泛用于密码学 概率性，有极低误判可能
AKS 确定性 $O((\log n)^{6-12})$ 理论上完美，无依赖 实际运行极慢，常数大[citation:9]
ECPP 确定性 启发式多项式 可处理万位大数 复杂度分析复杂[citation:5]

📝 历史背景与优化：

AKS算法由印度理工学院的三位学者在2002年提出，论文标题为《PRIMES is in P》[citation:3]。这一发现震惊了数学界和计算机科学界，因为它结束了几个世纪以来关于素数判定复杂性的争论。

优化版本： 原始AKS算法的复杂度为 $O((\log n)^{12})$，经过多次改进：

  • Bernstein提出了优化版本，将复杂度降至 $O((\log n)^6)$[citation:6]。
  • Lenstra和Pomerance进一步改进，提出了更实用的变体。
  • 对于 $2^{13}-1$ 这样的数，高效实现仍需约30分钟[citation:8]。
  • 改进后的算法在Pentium IV/1.8G上可在几十秒内完成部分测试[citation:6]。

实际应用： 尽管AKS具有理论上的完美性，但在实际密码学应用中（如RSA密钥生成），Miller-Rabin测试仍是首选，因为它足够快且误判率可忽略不计。AKS主要用于学术研究和理论验证[citation:10]。

算法变体：

  • 循环群AKS测试： 利用分圆域的性质改进效率。
  • 改进版AKS： 优化参数选择，缩小 $a$ 的检验范围。
  • AKS-Bernstein第二算法： 在PC上实现了较好的实际运行效率[citation:6]。
