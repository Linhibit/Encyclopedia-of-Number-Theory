模逆元 (Modular Inverse)

定义与存在条件：

设 $a$ 和 $m$ 为整数，$m \gt 0$。如果存在整数 $x$ 使得： $$ax \equiv 1 \pmod{m}$$ 则称 $x$ 为 $a$ 模 $m$ 的逆元，记作 $a^{-1} \pmod{m}$。

存在性定理： $a$ 模 $m$ 的逆元存在当且仅当 $\gcd(a, m) = 1$（即 $a$ 与 $m$ 互质）。

当逆元存在时，在模 $m$ 意义下是唯一的（通常取 $0 \leq x \lt m$ 的那个）。

计算方法：

方法一：扩展欧几里得算法（通用方法）

要求 $ax \equiv 1 \pmod{m}$，等价于求方程 $ax + my = 1$ 的整数解 $x$。 使用扩展欧几里得算法可以求出 $\gcd(a, m)$ 以及满足 $ax + my = \gcd(a, m)$ 的 $x, y$。 当 $\gcd(a, m) = 1$ 时，得到的 $x$ 就是 $a$ 模 $m$ 的逆元（可能需要调整到 $0 \leq x \lt m$）。

方法二：快速幂法（费马小定理，仅当 $m$ 为质数）

如果 $m$ 是质数，记 $m = p$，根据费马小定理： $$a^{p-1} \equiv 1 \pmod{p}$$ 因此 $a \cdot a^{p-2} \equiv 1 \pmod{p}$，即 $a$ 模 $p$ 的逆元为 $a^{p-2} \pmod{p}$。 使用快速幂算法可以高效计算 $a^{p-2} \bmod p$。

方法三：欧拉定理（$m$ 为合数但 $a$ 与 $m$ 互质）

如果 $\gcd(a, m) = 1$，根据欧拉定理： $$a^{\varphi(m)} \equiv 1 \pmod{m}$$ 其中 $\varphi(m)$ 是欧拉函数。因此 $a$ 模 $m$ 的逆元为 $a^{\varphi(m)-1} \pmod{m}$。

方法选择建议：
  • 扩展欧几里得算法：通用，适用于任意模数 $m$（只要逆元存在），时间复杂度 $O(\log m)$。
  • 快速幂法：仅当 $m$ 为质数时使用，时间复杂度 $O(\log m)$。
  • 欧拉定理法：需要计算 $\varphi(m)$，通常只在 $\varphi(m)$ 容易计算时使用。

代码示例 (C++)

线性求逆元原理：
对于质数模数 $p$，要求 $1$ 到 $n$（$n \lt p$）的所有逆元，可以使用递推公式： $$\text{inv}[i] = p - \lfloor p/i \rfloor \times \text{inv}[p \bmod i] \bmod p$$ 其中 $\text{inv}[1] = 1$。该公式基于以下推导： $$p = \lfloor p/i \rfloor \times i + (p \bmod i) \equiv 0 \pmod{p}$$ 所以 $\lfloor p/i \rfloor \times i \equiv -(p \bmod i) \pmod{p}$， 两边乘以 $\text{inv}[i] \times \text{inv}[p \bmod i]$ 即得递推式。 


// 模逆元示例：三种常用求逆元方法
#include <iostream>
#include <vector>
using namespace std;

// 扩展欧几里得算法：求 ax + by = gcd(a, b) 的一组解
long long extgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    long long x1, y1;
    long long g = extgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

// 方法1：扩展欧几里得算法求逆元（通用）
long long modInverseExtendedEuclidean(long long a, long long m) {
    long long x, y;
    long long g = extgcd(a, m, x, y);
    // 如果 gcd 不为 1，则逆元不存在
    if (g != 1) return -1;
    // 调整 x 到 [0, m) 范围内
    return ((x % m) + m) % m;
}

// 快速幂算法
long long fastPow(long long base, long long exp, long long mod) {
    if (mod == 1) return 0;
    long long result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) result = result * base % mod;
        exp >>= 1;
        base = base * base % mod;
    }
    return result;
}

// 方法2：快速幂法求逆元（仅当 m 为质数）
long long modInverseFermat(long long a, long long m) {
    // 假设 m 是质数，根据费马小定理
    return fastPow(a, m - 2, m);
}

// 方法3：预计算逆元（线性求逆元，适用于求 1 到 n 的所有逆元）
vector<long long> modInverseLinear(int n, long long mod) {
    vector<long long> inv(n + 1);
    inv[1] = 1;
    for (int i = 2; i <= n; i++) {
        // 公式：inv[i] = mod - mod / i * inv[mod % i] % mod
        inv[i] = mod - (mod / i) * inv[mod % i] % mod;
    }
    return inv;
}

int main() {
    cout << "=== 扩展欧几里得算法求逆元 ===" << '\n';
    cout << "5 模 11 的逆元: " << modInverseExtendedEuclidean(5, 11) << '\n'; // 9，因为 5*9=45≡1 mod 11
    cout << "7 模 13 的逆元: " << modInverseExtendedEuclidean(7, 13) << '\n'; // 2，因为 7*2=14≡1 mod 13

    long long inv68 = modInverseExtendedEuclidean(6, 8);
    if (inv68 == -1) {
        cout << "逆元不存在：gcd(6, 8) = 2 ≠ 1" << '\n';
    } else {
        cout << "6 模 8 的逆元: " << inv68 << '\n';
    }

    cout << '\n' << "=== 费马小定理求逆元（模为质数） ===" << '\n';
    cout << "5 模 11 的逆元: " << modInverseFermat(5, 11) << '\n'; // 9
    cout << "7 模 13 的逆元: " << modInverseFermat(7, 13) << '\n'; // 2

    cout << '\n' << "=== 线性求逆元（求 1 到 5 模 7 的逆元） ===" << '\n';
    vector<long long> inv = modInverseLinear(5, 7);
    for (int i = 1; i <= 5; i++) {
        cout << i << " 模 7 的逆元: " << inv[i] << '\n';
    }

    return 0;
}

示例：

示例1：扩展欧几里得算法求逆元
求 $5$ 模 $11$ 的逆元。
解：需要解 $5x \equiv 1 \pmod{11}$，即 $5x + 11y = 1$。
使用扩展欧几里得算法： $$ \begin{aligned} 11 &= 5 \times 2 + 1 \\ 5 &= 1 \times 5 + 0 \end{aligned} $$ 回代：$1 = 11 - 5 \times 2$，所以 $x = -2$，调整到模 $11$ 下为 $-2 \equiv 9 \pmod{11}$。
验证：$5 \times 9 = 45 \equiv 1 \pmod{11}$。

示例2：费马小定理求逆元
求 $7$ 模 $13$ 的逆元（$13$ 是质数）。
根据费马小定理：$7^{13-2} = 7^{11} \equiv 7^{-1} \pmod{13}$。
计算 $7^{11} \bmod 13$： $$ \begin{aligned} 7^2 &= 49 \equiv 10 \pmod{13} \\ 7^4 &= (7^2)^2 \equiv 10^2 = 100 \equiv 9 \pmod{13} \\ 7^8 &= (7^4)^2 \equiv 9^2 = 81 \equiv 3 \pmod{13} \\ 7^{11} &= 7^8 \times 7^2 \times 7^1 \equiv 3 \times 10 \times 7 = 210 \equiv 2 \pmod{13} \end{aligned} $$ 所以 $7^{-1} \equiv 2 \pmod{13}$。
验证：$7 \times 2 = 14 \equiv 1 \pmod{13}$。

示例3：线性求逆元
求 $1$ 到 $5$ 模 $7$ 的逆元（$7$ 是质数）。
使用递推公式：

  • $\text{inv}[1] = 1$
  • $\text{inv}[2] = 7 - \lfloor 7/2 \rfloor \times \text{inv}[7 \bmod 2] \bmod 7 = 7 - 3 \times \text{inv}[1] = 7 - 3 = 4$
  • $\text{inv}[3] = 7 - \lfloor 7/3 \rfloor \times \text{inv}[7 \bmod 3] \bmod 7 = 7 - 2 \times \text{inv}[1] = 7 - 2 = 5$
  • $\text{inv}[4] = 7 - \lfloor 7/4 \rfloor \times \text{inv}[7 \bmod 4] \bmod 7 = 7 - 1 \times \text{inv}[3] = 7 - 5 = 2$
  • $\text{inv}[5] = 7 - \lfloor 7/5 \rfloor \times \text{inv}[7 \bmod 5] \bmod 7 = 7 - 1 \times \text{inv}[2] = 7 - 4 = 3$

应用：

  1. 模除运算： 在模运算中，除法 $a/b \pmod{m}$ 定义为 $a \times b^{-1} \pmod{m}$， 其中 $b^{-1}$ 是 $b$ 模 $m$ 的逆元。
  2. 密码学： RSA、ElGamal 等公钥密码系统中需要大量模逆元计算。
  3. 组合数学： 计算组合数 $C_n^k \bmod p$ 时，需要用到逆元来计算阶乘的逆元。
  4. 解线性同余方程： 方程 $ax \equiv b \pmod{m}$ 的解为 $x \equiv a^{-1}b \pmod{m}$（当 $\gcd(a,m)=1$）。
  5. 中国剩余定理： 在构造解时需要计算模逆元。

📝 注意：

1. 逆元存在的充要条件是 $\gcd(a, m) = 1$。如果 $\gcd(a, m) \neq 1$，则 $a$ 模 $m$ 的逆元不存在。
2. 当模数 $m$ 为质数时，可以使用费马小定理求逆元，否则一般使用扩展欧几里得算法。
3. 线性求逆元方法仅适用于求连续整数的逆元，且模数 $m$ 必须是质数。
4. 在实际编程中，通常预处理阶乘及其逆元，以便快速计算组合数。

扩展： 对于合数模数 $m$，如果 $\gcd(a, m) = 1$，逆元仍然存在，但费马小定理不再适用， 必须使用扩展欧几里得算法或欧拉定理法。
