数论变换 (Number Theoretic Transform, NTT)

算法原理：

数论变换是离散傅里叶变换（DFT）在有限域（模素数环）上的类比。与使用复数单位根的DFT不同，NTT使用模素数 $p$ 下的原根作为变换基，实现了无浮点误差的多项式乘法。

核心概念：

  1. 原根： 若 $g$ 是模 $p$ 的原根，则 $g^0, g^1, \dots, g^{p-2}$ 模 $p$ 互不相同，且 $g^{p-1} \equiv 1 \pmod{p}$。
  2. 单位根： 设 $n$ 是 $p-1$ 的因子，定义 $\omega_n = g^{(p-1)/n} \bmod p$，则 $\omega_n$ 是模 $p$ 下的 $n$ 次单位根，满足 $\omega_n^n \equiv 1 \pmod{p}$。
  3. 变换条件： NTT要求 $n$ 是2的幂且 $n \mid (p-1)$，即 $p = k \cdot n + 1$。
  4. 卷积定理： 时域卷积对应频域逐点乘积，实现 $O(n \log n)$ 多项式乘法。

对比FFT：

  • 精度： NTT使用整数模运算，无浮点误差；FFT存在精度问题。
  • 适用性： NTT适用于模素数环计算，在密码学、大整数乘法中关键；FFT适用于一般信号处理。
  • 限制： NTT对模数 $p$ 有特殊要求（需存在 $n$ 次单位根）。

算法步骤：

  1. 参数选择： 选择模数 $p$ 和变换长度 $n$，满足：
    1. $p$ 是素数
    2. $n$ 是2的幂
    3. $n \mid (p-1)$，即 $p = k \cdot n + 1$
    常用NTT友好模数：
    • $p = 998244353 = 119 \times 2^{23} + 1$，原根 $g = 3$（最常用）
    • $p = 1004535809 = 479 \times 2^{21} + 1$，原根 $g = 3$
    • $p = 469762049 = 7 \times 2^{26} + 1$，原根 $g = 3$
  2. 正向NTT（系数表示 → 点值表示）：
    1. 若 $n=1$，直接返回
    2. 将多项式按奇偶索引分成两个长度为 $n/2$ 的多项式：$A_0$（偶项）、$A_1$（奇项）
    3. 递归计算 $A_0$ 和 $A_1$ 在 $\omega_n^{2k}$ 处的值
    4. 合并结果（蝴蝶操作）： $$A(\omega_n^k) = A_0(\omega_n^{2k}) + \omega_n^k A_1(\omega_n^{2k})$$ $$A(\omega_n^{k+n/2}) = A_0(\omega_n^{2k}) - \omega_n^k A_1(\omega_n^{2k})$$
  3. 逆向NTT（点值表示 → 系数表示）： 与正向NTT类似，但：
    1. 使用 $\omega_n^{-1}$ 作为单位根
    2. 最终结果乘以 $n^{-1} \bmod p$（模逆元）
  4. 多项式乘法：
    1. 设两个多项式 $A(x)$、$B(x)$，长度分别为 $m_1$、$m_2$
    2. 取 $n = 2^{\lceil \log_2(m_1 + m_2 - 1) \rceil}$（大于等于 $m_1+m_2-1$ 的最小2的幂）
    3. $A$、$B$ 补零至长度 $n$
    4. 分别计算 NTT($A$)、NTT($B$)
    5. 频域逐点相乘：$C[k] = A[k] \cdot B[k] \bmod p$
    6. 计算逆NTT($C$)，得到乘积多项式系数
复杂度分析：
  • 时间复杂度：$O(n \log n)$，与FFT相同。
  • 空间复杂度：$O(n)$，可以原地计算（迭代版本）。
  • 由于使用模运算，避免了浮点误差，特别适合需要精确结果的场合。
  • 对于特定的模数（如998244353），可以使用预计算的原根幂次来加速。

示例：

示例1： 使用 $p = 17$ 的NTT。

解法：

  1. $p = 17$，原根 $g = 3$（验证：$3^0,3^1,\dots,3^{15}$ 模17互不相同）
  2. 取 $n = 4$（因为 $4 \mid 16$，且 $4$ 是2的幂）
  3. 计算 $4$ 次单位根：$\omega_4 = g^{(17-1)/4} = 3^4 = 13 \bmod 17$
  4. 对于多项式 $A(x) = 1 + 2x + 3x^2 + 4x^3$：
    • 计算在 $\omega_4^0=1, \omega_4^1=13, \omega_4^2=16, \omega_4^3=4$ 处的值
    • 可以使用蝴蝶操作递归计算

示例2： 使用 $p = 998244353$ 计算多项式乘法 $A(x) = 1 + 2x + 3x^2$ 与 $B(x) = 4 + 5x + 6x^2$。

解法：

  1. 两个多项式长度都是3，乘积长度最多为5，所以取 $n=8$（大于5的最小2的幂）。
  2. 将 $A$ 和 $B$ 补零到长度8：$A = [1,2,3,0,0,0,0,0]$，$B = [4,5,6,0,0,0,0,0]$。
  3. 分别计算 NTT($A$) 和 NTT($B$)。
  4. 逐点相乘得到 NTT($C$)。
  5. 计算逆 NTT 得到 $C$。
  6. 结果应为 $C = [4, 13, 28, 27, 18, 0, 0, 0]$，即 $4 + 13x + 28x^2 + 27x^3 + 18x^4$。

示例3： 验证卷积定理。

直接计算卷积：$c_k = \sum_{i+j=k} a_i b_j$。 对于上面的例子：

  • $c_0 = a_0 b_0 = 1 \times 4 = 4$
  • $c_1 = a_0 b_1 + a_1 b_0 = 1 \times 5 + 2 \times 4 = 13$
  • $c_2 = a_0 b_2 + a_1 b_1 + a_2 b_0 = 1 \times 6 + 2 \times 5 + 3 \times 4 = 28$
  • $c_3 = a_1 b_2 + a_2 b_1 = 2 \times 6 + 3 \times 5 = 27$
  • $c_4 = a_2 b_2 = 3 \times 6 = 18$
与NTT计算结果一致。

代码示例 (C++)


#include <iostream>
#include <vector>
#include <algorithm>
#include <cstdint>
#include <random>
using namespace std;

using ll = long long;

// 快速幂（模意义下）
ll modPow(ll base, ll exp, ll mod) {
    base %= mod;
    ll result = 1;
    while (exp > 0) {
        if (exp & 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}

// 扩展欧几里得求逆元
ll modInv(ll a, ll mod) {
    ll old_r = a % mod, r = mod;
    ll old_s = 1, s = 0;
    while (r != 0) {
        ll q = old_r / r;
        ll tr = r;         r = old_r - q * r;         old_r = tr;
        ll ts = s;         s = old_s - q * s;         old_s = ts;
    }
    return (old_s % mod + mod) % mod;
}

// 迭代版NTT（原地计算，位逆序置换）
void ntt(vector<ll>& a, bool invert, ll mod, ll root) {
    int n = a.size();

    // 位逆序置换
    for (int i = 1, j = 0; i < n; i++) {
        int bit = n >> 1;
        for (; j & bit; bit >>= 1) j ^= bit;
        j ^= bit;
        if (i < j) swap(a[i], a[j]);
    }

    // 蝴蝶操作
    for (int len = 2; len <= n; len <<= 1) {
        ll wlen = modPow(root, (mod - 1) / len, mod);
        if (invert) wlen = modInv(wlen, mod);
        for (int i = 0; i < n; i += len) {
            ll w = 1;
            int half = len >> 1;
            for (int j = 0; j < half; j++) {
                ll u = a[i + j];
                ll v = a[i + j + half] * w % mod;
                a[i + j] = (u + v) % mod;
                a[i + j + half] = (u - v + mod) % mod;
                w = w * wlen % mod;
            }
        }
    }

    // 逆变换乘以 n^{-1}
    if (invert) {
        ll nInv = modInv(n, mod);
        for (ll& x : a) x = x * nInv % mod;
    }
}

const ll MOD1 = 998244353;    // 119 * 2^23 + 1，原根 3
const ll MOD2 = 1004535809;   // 479 * 2^21 + 1，原根 3
const ll ROOT = 3;

// 多项式乘法（使用NTT）
vector<ll> polyMultiply(const vector<ll>& a, const vector<ll>& b, ll mod = MOD1) {
    int need = (int)a.size() + (int)b.size() - 1;
    int n = 1;
    while (n < need) n <<= 1;

    vector<ll> fa(n, 0), fb(n, 0);
    for (size_t i = 0; i < a.size(); i++) fa[i] = a[i] % mod;
    for (size_t i = 0; i < b.size(); i++) fb[i] = b[i] % mod;

    ntt(fa, false, mod, ROOT);
    ntt(fb, false, mod, ROOT);
    for (int i = 0; i < n; i++) fa[i] = fa[i] * fb[i] % mod;
    ntt(fa, true, mod, ROOT);

    fa.resize(need);
    return fa;
}

// 直接卷积验证
vector<ll> directConvolution(const vector<ll>& a, const vector<ll>& b) {
    vector<ll> result(a.size() + b.size() - 1);
    for (size_t i = 0; i < a.size(); i++)
        for (size_t j = 0; j < b.size(); j++)
            result[i + j] += a[i] * b[j];
    return result;
}

// 直接模卷积验证
vector<ll> modConvolution(const vector<ll>& a, const vector<ll>& b, ll mod) {
    vector<ll> result(a.size() + b.size() - 1);
    for (size_t i = 0; i < a.size(); i++)
        for (size_t j = 0; j < b.size(); j++)
            result[i + j] = (result[i + j] + a[i] * b[j]) % mod;
    return result;
}

void printPoly(const string& name, const vector<ll>& a) {
    cout << name << ": [";
    for (size_t i = 0; i < a.size(); i++) {
        if (i) cout << ", ";
        cout << a[i];
    }
    cout << "]\n";
}

int main() {
    cout << "=== 数论变换 (NTT) 示例 ===\n";

    // 示例1：简单多项式乘法
    vector<ll> polyA = {1, 2, 3}; // 1 + 2x + 3x^2
    vector<ll> polyB = {4, 5, 6}; // 4 + 5x + 6x^2
    printPoly("多项式 A", polyA);
    printPoly("多项式 B", polyB);

    vector<ll> result = polyMultiply(polyA, polyB);
    printPoly("乘积 (使用NTT)", result);
    cout << "预期结果: [4, 13, 28, 27, 18]\n";
    printPoly("直接卷积结果", directConvolution(polyA, polyB));

    // 示例2：大系数多项式（模意义下）
    vector<ll> bigPolyA = {123456789, 987654321, 555555555};
    vector<ll> bigPolyB = {111111111, 222222222, 333333333};
    cout << "\n大系数多项式乘法:\n";
    printPoly("A", bigPolyA);
    printPoly("B", bigPolyB);

    vector<ll> bigResult = polyMultiply(bigPolyA, bigPolyB);
    printPoly("乘积 (模 998244353)", bigResult);
    vector<ll> directMod = modConvolution(bigPolyA, bigPolyB, MOD1);
    printPoly("直接模卷积", directMod);
    cout << "结果一致? " << (bigResult == directMod ? "true" : "false") << "\n";

    // 示例3：使用不同的NTT友好模数
    vector<ll> testA = {1, 2, 3, 4};
    vector<ll> testB = {5, 6, 7, 8};
    cout << "\n=== 使用不同模数的NTT ===\n";
    printPoly("使用模数 998244353", polyMultiply(testA, testB));
    printPoly("使用模数 1004535809", polyMultiply(testA, testB, MOD2));
    cout << "两个结果在各自模数下都正确\n";

    // 示例4：长多项式乘法（性能测试）
    cout << "\n=== 性能测试 ===\n";
    int len = 1 << 16; // 65536
    cout << "生成两个长度为 " << len << " 的多项式...\n";
    mt19937 rng(12345); // 固定种子便于复现
    uniform_int_distribution<int> dist(0, 999);
    vector<ll> longA(len), longB(len);
    for (int i = 0; i < len; i++) {
        longA[i] = dist(rng);
        longB[i] = dist(rng);
    }
    vector<ll> longResult = polyMultiply(longA, longB);
    cout << "结果长度: " << longResult.size() << "\n";

    return 0;
}

应用：

  1. 大整数乘法： 通过将整数表示为多项式（基为 $B$，如 $B=10$ 或 $B=2^{32}$），使用NTT计算多项式乘积，从而实现大整数乘法。这是目前最快的大整数乘法算法之一。
  2. 密码学： 在格密码、同态加密等现代密码学方案中，NTT用于高效计算多项式环上的运算。
  3. 编码理论： 在纠错码（如Reed-Solomon码）的编码和解码中，NTT可以加速计算。
  4. 信号处理： 与FFT类似，NTT可以用于数字信号处理，但适用于需要精确模运算的场合。
  5. 实际应用： 当需要计算大系数多项式乘法或大整数乘法时，NTT 是常用工具。

与FFT的比较：

特性 FFT NTT
数域 复数 有限域（模素数）
精度 浮点误差 精确
速度 快（硬件加速） 快（整数运算）
适用性 通用信号处理 密码学、精确计算
限制 数值稳定性问题 模数需满足 $n \mid (p-1)$

📝 历史背景与扩展：

数论变换是离散傅里叶变换在有限域上的推广，最早由Pollard在1971年提出。随着密码学和大整数运算需求的增长，NTT在现代密码学（特别是后量子密码学）和大数运算库中变得至关重要。

优化技巧： 1. 迭代实现：与FFT类似，NTT可以使用迭代版本避免递归开销，并使用位逆序置换优化。
2. 预计算单位根：预先计算所有需要的单位根幂次，避免重复计算。
3. 使用多个模数：对于特别大的整数乘法，可以使用多个NTT友好模数分别计算，然后用中国剩余定理（CRT）组合结果，从而避免模数限制。
4. 选择适当的模数：常用的NTT友好模数有：

  • $998244353 = 119 \times 2^{23} + 1$（最常用）
  • $1004535809 = 479 \times 2^{21} + 1$
  • $469762049 = 7 \times 2^{26} + 1$
5. 注意系数范围：使用单个模数时，乘积系数必须小于模数。对于大系数，需要使用多个模数或减少系数。
6. 与FFT结合：有时可以使用FFT进行初步计算，然后用NTT进行验证或精确化。
