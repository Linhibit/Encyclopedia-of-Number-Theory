洲阁筛 (Zhouge Sieve)

算法原理：

洲阁筛是一种用于计算积性函数前缀和的通用算法，由中国选手洲阁（周楷文）在2012年提出。它通过分段筛法和递归思想，能够处理更广泛的积性函数类，特别是那些在素数幂处取值有特定多项式形式的函数。

核心思想：

  1. 函数分解： 将目标函数 $f(n)$ 分解为两部分：$f(n) = \sum_{d|n} g(d) h(n/d)$，其中 $g$ 和 $h$ 是更简单的函数。
  2. 分段处理： 将 $[1, n]$ 分成若干段，分别处理每段中的函数值。
  3. 递归计算： 对于每个素数 $p$，递归计算 $f$ 在 $p$ 的幂次上的贡献。
  4. 前缀和合并： 将所有段的贡献合并，得到最终的前缀和。

适用条件： 洲阁筛适用于满足以下条件的积性函数 $f$：

  • $f(p)$ 是关于 $p$ 的多项式函数（$p$ 为素数）
  • $f(p^k)$ 可以快速计算（$k \geq 2$）
  • 函数在素数幂处的值有特定的递推关系

算法步骤：

  1. 预处理：
    1. 计算 $\pi(\sqrt{n})$ 以内的所有素数
    2. 预处理 $f(p)$ 和 $f(p^k)$ 的值（$p \leq \sqrt{n}$, $k \geq 2$）
    3. 构建分段大小 $L = \lfloor \sqrt{n} \rfloor$
  2. 计算 $g$ 函数： 定义 $g(x)$ 为只被 $\leq \sqrt{n}$ 的素数整除的数的 $f$ 值前缀和。
    1. 初始化 $g(i) = 1$（对应常数函数）
    2. 对于每个素数 $p \leq \sqrt{n}$，从大到小更新： $$g(i) \leftarrow g(i) - f(p) \cdot g(\lfloor i/p \rfloor)$$
    3. 最终 $g(i)$ 表示 $[1, i]$ 中不被 $\leq \sqrt{n}$ 的素数整除的数的个数（乘以相应的函数值）
  3. 计算 $S$ 函数： 定义 $S(n, m)$ 表示 $[1, n]$ 中最小质因子大于第 $m$ 个素数的数的 $f$ 值之和。
    1. 边界条件：$S(n, 0) = \sum_{i=1}^n f(i)$（需要计算）
    2. 递归关系： $$S(n, m) = S(n, m-1) - f(p_m) \cdot S(\lfloor n/p_m \rfloor, m-1)$$
    3. 当 $n \lt p_m^2$ 时，可以直接计算
  4. 合并结果： 最终前缀和为： $$\sum_{i=1}^n f(i) = S(n, \pi(\sqrt{n})) + \sum_{\substack{p \leq \sqrt{n} \\ k \geq 1}} f(p^k) \cdot S\left(\lfloor n/p^k \rfloor, \pi(p)\right)$$
  5. 优化：
    • 使用整数分块减少递归调用
    • 记忆化已计算的 $S(n, m)$ 值
    • 预处理小范围内的函数值
复杂度分析：
  • 时间复杂度：$O\left(\frac{n^{3/4}}{\log n}\right)$
  • 空间复杂度：$O(\sqrt{n})$
  • 比杜教筛更通用，但实现更复杂
  • 适用于 $n$ 高达 $10^{11}$ 甚至更大的情况

经典应用：

例1：计算素数计数函数 $\pi(n)$
虽然不是直接计算积性函数，但洲阁筛可以用于计算不超过 $n$ 的素数个数。 定义函数 $f(n) = 1$ 当 $n$ 是素数，否则为 0。 虽然不是积性函数，但可以通过构造辅助函数使用洲阁筛思想。

例2：计算 $f(n) = n^k$ 的前缀和
对于 $f(n) = n^k$，其中 $k$ 是固定整数。 $f$ 是完全积性函数，$f(p) = p^k$ 是多项式。 洲阁筛可以直接应用。

例3：计算 $\sigma_k(n)$ 的前缀和
其中 $\sigma_k(n) = \sum_{d|n} d^k$ 是除数函数。 $\sigma_k(n)$ 是积性函数，且 $\sigma_k(p) = 1 + p^k$ 是多项式。 洲阁筛适用。

例4：计算 $f(n) = \mu(n)^2$（无平方因子数的特征函数）
$f(n) = 1$ 当 $n$ 无平方因子，否则为 0。 虽然不是积性函数，但可以通过洲阁筛的变体计算。

代码示例 (C++)


// 洲阁筛 / 杜教筛实现 - 计算数论函数前缀和
// 以莫比乌斯函数 μ(n) 与欧拉函数 φ(n) 为例。
#include <iostream>
#include <vector>
#include <unordered_map>
#include <cmath>
#include <algorithm>
#include <chrono>
using namespace std;

// 朴素计算单个数的欧拉函数（用于小值验证）
long long eulerPhi(long long x) {
    long long res = x, t = x;
    for (long long p = 2; p * p <= t; p++) {
        if (t % p == 0) {
            res = res / p * (p - 1);
            while (t % p == 0) t /= p;
        }
    }
    if (t > 1) res = res / t * (t - 1);
    return res;
}

// 朴素计算单个数的莫比乌斯函数（用于小值验证）
long long mobius(long long x) {
    long long t = x;
    int cnt = 0;
    for (long long p = 2; p * p <= t; p++) {
        if (t % p == 0) {
            int e = 0;
            while (t % p == 0) { t /= p; e++; }
            if (e > 1) return 0;
            cnt++;
        }
    }
    if (t > 1) cnt++;
    return (cnt % 2 == 0) ? 1 : -1;
}

class ZhougeSieve {
    long long n;                      // 目标上界
    int limit;                        // 线性筛预处理上界（约 n^{2/3}）
    vector<int> primes;               // 素数列表
    vector<bool> isPrime;
    vector<long long> mu, phi;        // 单点函数值
    vector<long long> sumMu, sumPhi;  // 前缀和
    unordered_map<long long, long long> memoMu, memoPhi;  // 记忆化

public:
    explicit ZhougeSieve(long long n_) : n(n_) {
        long long l = (long long)pow((double)n, 2.0 / 3.0) + 2;
        limit = (int)min(n, l);
        if (limit < 1) limit = 1;
        linearSieve(limit);
    }

    // 线性筛预处理 μ 与 φ 及其前缀和
    void linearSieve(int L) {
        mu.assign(L + 1, 0);
        phi.assign(L + 1, 0);
        sumMu.assign(L + 1, 0);
        sumPhi.assign(L + 1, 0);
        isPrime.assign(L + 1, true);
        isPrime[0] = isPrime[1] = false;
        mu[1] = 1;
        phi[1] = 1;
        for (int i = 2; i <= L; i++) {
            if (isPrime[i]) {
                primes.push_back(i);
                mu[i] = -1;
                phi[i] = i - 1;
            }
            for (int p : primes) {
                long long num = 1LL * i * p;
                if (num > L) break;
                isPrime[num] = false;
                if (i % p == 0) {
                    mu[num] = 0;
                    phi[num] = phi[i] * p;
                    break;
                } else {
                    mu[num] = -mu[i];
                    phi[num] = phi[i] * (p - 1);
                }
            }
        }
        for (int i = 1; i <= L; i++) {
            sumMu[i] = sumMu[i - 1] + mu[i];
            sumPhi[i] = sumPhi[i - 1] + phi[i];
        }
    }

    // 杜教筛递推：M(x) = 1 - Σ_{l=2..x} (r-l+1) * M(⌊x/l⌋)
    long long S_mu(long long x) {
        if (x <= limit) return sumMu[x];
        auto it = memoMu.find(x);
        if (it != memoMu.end()) return it->second;
        long long res = 1;
        for (long long l = 2, r; l <= x; l = r + 1) {
            long long q = x / l;
            r = x / q;
            res -= (r - l + 1) * S_mu(q);
        }
        memoMu[x] = res;
        return res;
    }

    // 杜教筛递推：Φ(x) = x(x+1)/2 - Σ_{l=2..x} (r-l+1) * Φ(⌊x/l⌋)
    long long S_phi(long long x) {
        if (x <= limit) return sumPhi[x];
        auto it = memoPhi.find(x);
        if (it != memoPhi.end()) return it->second;
        long long res = x * (x + 1) / 2;
        for (long long l = 2, r; l <= x; l = r + 1) {
            long long q = x / l;
            r = x / q;
            res -= (r - l + 1) * S_phi(q);
        }
        memoPhi[x] = res;
        return res;
    }

    long long sumOfMu(long long x) { return S_mu(x); }
    long long sumOfPhi(long long x) { return S_phi(x); }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cout << "=== 洲阁筛示例 ===" << endl;
    long long n = 1000000000LL;  // 10^9
    cout << "计算 n = " << n << " 的前缀和" << endl;

    auto t0 = chrono::steady_clock::now();
    ZhougeSieve zg(n);
    auto t1 = chrono::steady_clock::now();
    cout << "初始化耗时: "
         << chrono::duration_cast<chrono::milliseconds>(t1 - t0).count()
         << " ms" << endl;

    long long sumPhi = zg.sumOfPhi(n);
    long long sumMu = zg.sumOfMu(n);
    cout << "Sφ(" << n << ") = " << sumPhi << endl;
    cout << "Sμ(" << n << ") = " << sumMu << endl;

    cout << endl << "=== 小数值验证 ===" << endl;
    long long smallN = 1000;
    long long directPhi = 0, directMu = 0;
    for (long long i = 1; i <= smallN; i++) {
        directPhi += eulerPhi(i);
        directMu += mobius(i);
    }
    ZhougeSieve zgSmall(smallN);
    long long sievePhi = zgSmall.sumOfPhi(smallN);
    long long sieveMu = zgSmall.sumOfMu(smallN);
    cout << "n=" << smallN << ":" << endl;
    cout << "直接计算 Sφ = " << directPhi << ", 洲阁筛 = " << sievePhi
         << ", 一致? " << (directPhi == sievePhi ? "是" : "否") << endl;
    cout << "直接计算 Sμ = " << directMu << ", 洲阁筛 = " << sieveMu
         << ", 一致? " << (directMu == sieveMu ? "是" : "否") << endl;

    cout << endl << "=== 性能对比 ===" << endl;
    long long testNs[] = {1000000, 10000000, 50000000};
    for (long long testN : testNs) {
        cout << "n = " << testN << ":" << endl;
        auto s0 = chrono::steady_clock::now();
        ZhougeSieve zgTest(testN);
        long long phiTest = zgTest.sumOfPhi(testN);
        auto s1 = chrono::steady_clock::now();
        cout << "Sφ(" << testN << ") = " << phiTest
             << " (耗时 "
             << chrono::duration_cast<chrono::milliseconds>(s1 - s0).count()
             << " ms)" << endl;
    }

    cout << endl << "=== 通用示例：计算 f(n) = n 的前缀和 ===" << endl;
    long long n2 = 1000000;
    long long computed = n2 * (n2 + 1) / 2;  // 1 + 2 + ... + n
    long long expected = 0;
    for (long long i = 1; i <= n2; i++) expected += i;
    cout << "计算值: " << computed << ", 期望值: " << expected
         << ", 一致? " << (computed == expected ? "是" : "否") << endl;

    return 0;
}

应用：

  1. 通用积性函数求和： 适用于各种积性函数的前缀和计算，特别是那些在素数处为多项式的函数。
  2. 素数计数函数： 可以用于计算 $\pi(n)$（不超过 $n$ 的素数个数），虽然不是直接计算积性函数。
  3. 除数函数： 计算 $\sigma_k(n)$、$d(n)$ 等除数函数的前缀和。
  4. 幂函数： 计算 $f(n) = n^k$ 的前缀和。
  5. 数论研究： 在研究数论函数的渐近性质时，需要计算大量前缀和作为实验数据。
  6. 实际应用： 在需要高效计算复杂积性函数前缀和的题目中，洲阁筛是强大工具。

与杜教筛的比较：

特性 杜教筛 洲阁筛
时间复杂度 $O(n^{2/3})$ $O\left(\frac{n^{3/4}}{\log n}\right)$
空间复杂度 $O(n^{2/3})$ $O(\sqrt{n})$
适用函数类 需要找到合适的辅助函数 $g$ 更广泛，特别是素数处为多项式的函数
实现难度 相对简单 较复杂
实际性能 对于常见函数很快 理论复杂度更好，常数较大
适用范围 $\varphi, \mu, d$ 等特定函数 更通用的积性函数

📝 优化与扩展：

1. 分段优化： 合理选择分段大小，平衡预处理和递归计算的开销。
2. 记忆化策略： 使用哈希表记忆化已计算的 $S(n, m)$ 值，避免重复计算。
3. 递归剪枝： 当 $p^2 \gt n$ 时可以直接计算，减少递归深度。
4. 多函数同时计算： 当需要计算多个相关函数时，可以共享预处理结果。
5. 并行计算： 洲阁筛的某些部分可以并行化，提高计算速度。
6. 与Min_25筛的关系： 洲阁筛与Min_25筛有密切联系，都是处理积性函数前缀和的强大工具。Min_25筛在某些情况下更简单高效。

历史背景： 洲阁筛由洲阁（周楷文）在2012年提出，并在2013年的论文中详细描述。 它是对传统筛法的重大改进，使得计算更大范围的积性函数前缀和成为可能。 洲阁筛及其变体（如 Min_25 筛）在现代数论计算与积性函数前缀和求解中发挥着重要作用。

注意： 洲阁筛的实现相对复杂，需要仔细处理递归边界和记忆化策略。 在实际应用中，通常需要根据具体问题调整算法参数和优化策略。
