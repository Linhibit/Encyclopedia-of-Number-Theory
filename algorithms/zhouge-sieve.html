洲阁筛 (Zhouge Sieve)

算法原理：

洲阁筛是一种用于计算积性函数前缀和的通用算法，由中国选手洲阁（周楷文）在2012年提出。它通过分段筛法和递归思想，能够处理更广泛的积性函数类，特别是那些在素数幂处取值有特定多项式形式的函数。

核心思想：

  1. 函数分解： 将目标函数 $f(n)$ 分解为两部分：$f(n) = \sum_{d|n} g(d) h(n/d)$，其中 $g$ 和 $h$ 是更简单的函数。
  2. 分段处理： 将 $[1, n]$ 分成若干段，分别处理每段中的函数值。
  3. 递归计算： 对于每个素数 $p$，递归计算 $f$ 在 $p$ 的幂次上的贡献。
  4. 前缀和合并： 将所有段的贡献合并，得到最终的前缀和。

适用条件： 洲阁筛适用于满足以下条件的积性函数 $f$：

  • $f(p)$ 是关于 $p$ 的多项式函数（$p$ 为素数）
  • $f(p^k)$ 可以快速计算（$k \geq 2$）
  • 函数在素数幂处的值有特定的递推关系

算法步骤：

  1. 预处理：
    1. 计算 $\pi(\sqrt{n})$ 以内的所有素数
    2. 预处理 $f(p)$ 和 $f(p^k)$ 的值（$p \leq \sqrt{n}$, $k \geq 2$）
    3. 构建分段大小 $L = \lfloor \sqrt{n} \rfloor$
  2. 计算 $g$ 函数： 定义 $g(x)$ 为只被 $\leq \sqrt{n}$ 的素数整除的数的 $f$ 值前缀和。
    1. 初始化 $g(i) = 1$（对应常数函数）
    2. 对于每个素数 $p \leq \sqrt{n}$，从大到小更新： $$g(i) \leftarrow g(i) - f(p) \cdot g(\lfloor i/p \rfloor)$$
    3. 最终 $g(i)$ 表示 $[1, i]$ 中不被 $\leq \sqrt{n}$ 的素数整除的数的个数（乘以相应的函数值）
  3. 计算 $S$ 函数： 定义 $S(n, m)$ 表示 $[1, n]$ 中最小质因子大于第 $m$ 个素数的数的 $f$ 值之和。
    1. 边界条件：$S(n, 0) = \sum_{i=1}^n f(i)$（需要计算）
    2. 递归关系： $$S(n, m) = S(n, m-1) - f(p_m) \cdot S(\lfloor n/p_m \rfloor, m-1)$$
    3. 当 $n < p_m^2$ 时，可以直接计算
  4. 合并结果： 最终前缀和为： $$\sum_{i=1}^n f(i) = S(n, \pi(\sqrt{n})) + \sum_{\substack{p \leq \sqrt{n} \\ k \geq 1}} f(p^k) \cdot S\left(\lfloor n/p^k \rfloor, \pi(p)\right)$$
  5. 优化：
    • 使用整数分块减少递归调用
    • 记忆化已计算的 $S(n, m)$ 值
    • 预处理小范围内的函数值
复杂度分析：
  • 时间复杂度：$O\left(\frac{n^{3/4}}{\log n}\right)$
  • 空间复杂度：$O(\sqrt{n})$
  • 比杜教筛更通用，但实现更复杂
  • 适用于 $n$ 高达 $10^{11}$ 甚至更大的情况

经典应用：

例1：计算素数计数函数 $\pi(n)$
虽然不是直接计算积性函数，但洲阁筛可以用于计算不超过 $n$ 的素数个数。 定义函数 $f(n) = 1$ 当 $n$ 是素数，否则为 0。 虽然不是积性函数，但可以通过构造辅助函数使用洲阁筛思想。

例2：计算 $f(n) = n^k$ 的前缀和
对于 $f(n) = n^k$，其中 $k$ 是固定整数。 $f$ 是完全积性函数，$f(p) = p^k$ 是多项式。 洲阁筛可以直接应用。

例3：计算 $\sigma_k(n)$ 的前缀和
其中 $\sigma_k(n) = \sum_{d|n} d^k$ 是除数函数。 $\sigma_k(n)$ 是积性函数，且 $\sigma_k(p) = 1 + p^k$ 是多项式。 洲阁筛适用。

例4：计算 $f(n) = \mu(n)^2$（无平方因子数的特征函数）
$f(n) = 1$ 当 $n$ 无平方因子，否则为 0。 虽然不是积性函数，但可以通过洲阁筛的变体计算。

代码示例 (JavaScript)：

// 洲阁筛实现 - 计算数论函数前缀和
class ZhougeSieve {
    constructor(n) {
        this.n = n;
        this.sqrtN = Math.floor(Math.sqrt(n));
        
        // 预处理素数
        this.primes = this.getPrimes(this.sqrtN);
        this.primeCount = this.primes.length;
        
        // 预处理小范围函数值
        this.smallLimit = Math.floor(Math.pow(n, 2/3));
        this.precomputed = this.precomputeSmall(this.smallLimit);
        
        // 记忆化
        this.memo = new Map();
    }
    
    // 线性筛获取素数
    getPrimes(limit) {
        const primes = [];
        const isPrime = new Array(limit + 1).fill(true);
        
        for (let i = 2; i <= limit; i++) {
            if (isPrime[i]) {
                primes.push(i);
            }
            for (const p of primes) {
                if (i * p > limit) break;
                isPrime[i * p] = false;
                if (i % p === 0) break;
            }
        }
        
        return primes;
    }
    
    // 预处理小范围的函数值
    precomputeSmall(limit) {
        // 这里以计算 μ(n) 和 φ(n) 为例
        const mu = new Array(limit + 1).fill(0);
        const phi = new Array(limit + 1).fill(0);
        const isPrime = new Array(limit + 1).fill(true);
        const primes = [];
        
        mu[1] = 1;
        phi[1] = 1;
        
        for (let i = 2; i <= limit; i++) {
            if (isPrime[i]) {
                primes.push(i);
                mu[i] = -1;
                phi[i] = i - 1;
            }
            
            for (const p of primes) {
                if (i * p > limit) break;
                
                const num = i * p;
                isPrime[num] = false;
                
                if (i % p === 0) {
                    mu[num] = 0;
                    phi[num] = phi[i] * p;
                    break;
                } else {
                    mu[num] = -mu[i];
                    phi[num] = phi[i] * (p - 1);
                }
            }
        }
        
        // 计算前缀和
        const sumMu = new Array(limit + 1).fill(0);
        const sumPhi = new Array(limit + 1).fill(0);
        
        for (let i = 1; i <= limit; i++) {
            sumMu[i] = sumMu[i - 1] + mu[i];
            sumPhi[i] = sumPhi[i - 1] + phi[i];
        }
        
        return { mu, phi, sumMu, sumPhi, primes };
    }
    
    // 洲阁筛核心：计算 S(n, m)
    // 表示 [1, n] 中最小质因子大于第 m 个素数的数的函数值之和
    S(n, m, funcType = 'phi') {
        if (n === 0) return 0;
        
        // 记忆化键
        const memoKey = `${n},${m},${funcType}`;
        if (this.memo.has(memoKey)) {
            return this.memo.get(memoKey);
        }
        
        // 如果 n 很小，直接返回预计算的值
        if (n <= this.smallLimit) {
            let result;
            if (funcType === 'phi') {
                result = this.precomputed.sumPhi[n];
            } else if (funcType === 'mu') {
                result = this.precomputed.sumMu[n];
            }
            this.memo.set(memoKey, result);
            return result;
        }
        
        // 如果 m = 0，表示没有素数限制
        if (m === 0) {
            // 需要计算 ∑ f(i) for i=1..n
            // 对于 φ(n)，有公式 ∑ φ(i) = n(n+1)/2 - ∑_{d=2}^n S(⌊n/d⌋, 0)
            // 这里使用递归计算
            let result;
            if (funcType === 'phi') {
                result = n * (n + 1) / 2;
                for (let l = 2, r; l <= n; l = r + 1) {
                    r = Math.floor(n / Math.floor(n / l));
                    result -= (r - l + 1) * this.S(Math.floor(n / l), 0, 'phi');
                }
            } else if (funcType === 'mu') {
                result = 1;
                for (let l = 2, r; l <= n; l = r + 1) {
                    r = Math.floor(n / Math.floor(n / l));
                    result -= (r - l + 1) * this.S(Math.floor(n / l), 0, 'mu');
                }
            }
            this.memo.set(memoKey, result);
            return result;
        }
        
        // 递归关系：S(n, m) = S(n, m-1) - f(p_m) * S(⌊n/p_m⌋, m-1)
        const p = this.primes[m - 1];
        
        // 如果 p^2 > n，可以直接计算
        if (p * p > n) {
            let result = this.S(n, m - 1, funcType);
            
            // 减去包含 p 作为最小质因子的数的贡献
            const count = Math.floor(n / p);
            if (count > 0) {
                let fValue;
                if (funcType === 'phi') {
                    fValue = p - 1; // φ(p) = p-1
                } else if (funcType === 'mu') {
                    fValue = -1; // μ(p) = -1
                }
                result -= fValue * this.S(count, m - 1, funcType);
            }
            
            this.memo.set(memoKey, result);
            return result;
        }
        
        // 一般情况
        let result = this.S(n, m - 1, funcType);
        
        // 减去 p 的贡献
        let currentP = p;
        let k = 1;
        
        while (currentP <= n) {
            const count = Math.floor(n / currentP);
            if (count === 0) break;
            
            let fValue;
            if (funcType === 'phi') {
                if (k === 1) {
                    fValue = p - 1; // φ(p) = p-1
                } else {
                    fValue = currentP - Math.floor(currentP / p); // φ(p^k) = p^k - p^(k-1)
                }
            } else if (funcType === 'mu') {
                if (k === 1) {
                    fValue = -1; // μ(p) = -1
                } else {
                    fValue = 0; // μ(p^k) = 0 for k ≥ 2
                    break; // 后续的 μ 值都是 0，可以提前结束
                }
            }
            
            result -= fValue * this.S(count, m - 1, funcType);
            
            currentP *= p;
            k++;
        }
        
        this.memo.set(memoKey, result);
        return result;
    }
    
    // 计算欧拉函数前缀和
    sumPhi(n) {
        if (n <= this.smallLimit) {
            return this.precomputed.sumPhi[n];
        }
        
        // 使用洲阁筛公式
        const m = this.primeCount;
        let result = this.S(n, m, 'phi');
        
        // 加上素数幂的贡献
        for (const p of this.primes) {
            let currentP = p * p;
            let k = 2;
            
            while (currentP <= n) {
                const count = Math.floor(n / currentP);
                if (count === 0) break;
                
                // φ(p^k) = p^k - p^(k-1)
                const phiValue = currentP - Math.floor(currentP / p);
                result += phiValue * this.S(count, this.getPrimeIndex(p), 'phi');
                
                currentP *= p;
                k++;
            }
        }
        
        return result;
    }
    
    // 计算莫比乌斯函数前缀和
    sumMu(n) {
        if (n <= this.smallLimit) {
            return this.precomputed.sumMu[n];
        }
        
        const m = this.primeCount;
        let result = this.S(n, m, 'mu');
        
        // 对于 μ，只有 p^1 有非零贡献（μ(p) = -1）
        // p^k for k ≥ 2 的 μ 值都是 0
        for (const p of this.primes) {
            const count = Math.floor(n / p);
            if (count === 0) break;
            
            // μ(p) = -1
            result += (-1) * this.S(count, this.getPrimeIndex(p), 'mu');
        }
        
        return result;
    }
    
    // 获取素数的索引
    getPrimeIndex(p) {
        // 简化实现：返回素数在列表中的索引
        // 实际中可能需要更高效的查找
        return this.primes.indexOf(p);
    }
}

// 更通用的洲阁筛模板
class GeneralZhougeSieve {
    constructor(n, f, fPrime, fPrimePower) {
        this.n = n;
        this.sqrtN = Math.floor(Math.sqrt(n));
        
        // 函数定义
        this.f = f;                     // 目标函数 f(n)
        this.fPrime = fPrime;           // f(p) for prime p
        this.fPrimePower = fPrimePower; // f(p^k) for k ≥ 2
        
        // 预处理素数
        this.primes = this.getPrimes(this.sqrtN);
        this.primeCount = this.primes.length;
        
        // 记忆化
        this.memo = new Map();
    }
    
    getPrimes(limit) {
        const primes = [];
        const isPrime = new Array(limit + 1).fill(true);
        
        for (let i = 2; i <= limit; i++) {
            if (isPrime[i]) {
                primes.push(i);
            }
            for (const p of primes) {
                if (i * p > limit) break;
                isPrime[i * p] = false;
                if (i % p === 0) break;
            }
        }
        
        return primes;
    }
    
    // 通用的 S(n, m) 计算
    S_general(n, m) {
        if (n === 0) return 0;
        
        const memoKey = `S_${n}_${m}`;
        if (this.memo.has(memoKey)) {
            return this.memo.get(memoKey);
        }
        
        // 边界条件
        if (m === 0) {
            // 需要计算 ∑_{i=1}^n f(i)
            // 这里可以使用递归或其它方法
            // 简化：假设我们可以直接计算小范围的
            let result = 0;
            for (let i = 1; i <= n; i++) {
                result += this.f(i);
            }
            this.memo.set(memoKey, result);
            return result;
        }
        
        const p = this.primes[m - 1];
        
        // 如果 p^2 > n
        if (p * p > n) {
            let result = this.S_general(n, m - 1);
            
            const count = Math.floor(n / p);
            if (count > 0) {
                const fPrimeVal = this.fPrime(p);
                result -= fPrimeVal * this.S_general(count, m - 1);
            }
            
            this.memo.set(memoKey, result);
            return result;
        }
        
        // 一般情况
        let result = this.S_general(n, m - 1);
        
        let currentP = p;
        let k = 1;
        
        while (currentP <= n) {
            const count = Math.floor(n / currentP);
            if (count === 0) break;
            
            let fValue;
            if (k === 1) {
                fValue = this.fPrime(p);
            } else {
                fValue = this.fPrimePower(p, k);
            }
            
            result -= fValue * this.S_general(count, m - 1);
            
            currentP *= p;
            k++;
        }
        
        this.memo.set(memoKey, result);
        return result;
    }
    
    // 计算前缀和
    sumF(n) {
        const m = this.primeCount;
        let result = this.S_general(n, m);
        
        // 加上素数幂的贡献
        for (const p of this.primes) {
            let currentP = p * p;
            let k = 2;
            
            while (currentP <= n) {
                const count = Math.floor(n / currentP);
                if (count === 0) break;
                
                const fValue = this.fPrimePower(p, k);
                const primeIndex = this.primes.indexOf(p);
                result += fValue * this.S_general(count, primeIndex);
                
                currentP *= p;
                k++;
            }
        }
        
        return result;
    }
}

应用：

  1. 通用积性函数求和： 适用于各种积性函数的前缀和计算，特别是那些在素数处为多项式的函数。
  2. 素数计数函数： 可以用于计算 $\pi(n)$（不超过 $n$ 的素数个数），虽然不是直接计算积性函数。
  3. 除数函数： 计算 $\sigma_k(n)$、$d(n)$ 等除数函数的前缀和。
  4. 幂函数： 计算 $f(n) = n^k$ 的前缀和。
  5. 数论研究： 在研究数论函数的渐近性质时，需要计算大量前缀和作为实验数据。
  6. 算法竞赛： 在需要高效计算复杂积性函数前缀和的题目中，洲阁筛是强大工具。

与杜教筛的比较：

特性 杜教筛 洲阁筛
时间复杂度 $O(n^{2/3})$ $O\left(\frac{n^{3/4}}{\log n}\right)$
空间复杂度 $O(n^{2/3})$ $O(\sqrt{n})$
适用函数类 需要找到合适的辅助函数 $g$ 更广泛，特别是素数处为多项式的函数
实现难度 相对简单 较复杂
实际性能 对于常见函数很快 理论复杂度更好，常数较大
适用范围 $\varphi, \mu, d$ 等特定函数 更通用的积性函数

📝 优化与扩展：

1. 分段优化： 合理选择分段大小，平衡预处理和递归计算的开销。
2. 记忆化策略： 使用哈希表记忆化已计算的 $S(n, m)$ 值，避免重复计算。
3. 递归剪枝： 当 $p^2 > n$ 时可以直接计算，减少递归深度。
4. 多函数同时计算： 当需要计算多个相关函数时，可以共享预处理结果。
5. 并行计算： 洲阁筛的某些部分可以并行化，提高计算速度。
6. 与Min_25筛的关系： 洲阁筛与Min_25筛有密切联系，都是处理积性函数前缀和的强大工具。Min_25筛在某些情况下更简单高效。

历史背景： 洲阁筛由中国算法竞赛选手洲阁（周楷文）在2012年提出，并在2013年的论文中详细描述。 它是对传统筛法的重大改进，使得计算更大范围的积性函数前缀和成为可能。 洲阁筛及其变体（如Min_25筛）在现代算法竞赛和数论计算中发挥着重要作用。

注意： 洲阁筛的实现相对复杂，需要仔细处理递归边界和记忆化策略。 在实际应用中，通常需要根据具体问题调整算法参数和优化策略。
