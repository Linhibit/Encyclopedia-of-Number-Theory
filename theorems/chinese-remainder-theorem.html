中国剩余定理 (Chinese Remainder Theorem, CRT)

定理内容：

设 $m_1, m_2, \dots, m_k$ 是两两互质的正整数，即对于 $i \neq j$，有 $\gcd(m_i, m_j) = 1$。

考虑同余方程组： $$ \begin{cases} x \equiv a_1 \pmod{m_1} \\ x \equiv a_2 \pmod{m_2} \\ \quad \vdots \\ x \equiv a_k \pmod{m_k} \end{cases} $$

令 $M = m_1 m_2 \cdots m_k$，$M_i = \dfrac{M}{m_i}$（即 $M_i$ 是除了 $m_i$ 外所有模数的乘积）。

由于 $\gcd(m_i, M_i) = 1$，存在整数 $t_i$ 满足 $M_i t_i \equiv 1 \pmod{m_i}$。 则原方程组的解为： $$x \equiv a_1 M_1 t_1 + a_2 M_2 t_2 + \cdots + a_k M_k t_k \pmod{M}$$

这个解在模 $M$ 意义下是唯一的。

证明简述：

第一步：验证构造的解满足所有同余方程
对于任意 $i$（$1 \leq i \leq k$），考虑 $x$ 模 $m_i$： $$ x \equiv \sum_{j=1}^k a_j M_j t_j \pmod{m_i} $$ 当 $j \neq i$ 时，$M_j$ 包含因子 $m_i$，所以 $M_j \equiv 0 \pmod{m_i}$。 因此： $$ x \equiv a_i M_i t_i \pmod{m_i} $$ 由 $t_i$ 的定义，$M_i t_i \equiv 1 \pmod{m_i}$，所以： $$ x \equiv a_i \cdot 1 \equiv a_i \pmod{m_i} $$

第二步：证明唯一性（模 $M$ 意义下）
假设 $x_1$ 和 $x_2$ 都是方程组的解，则对于每个 $i$，有： $$x_1 \equiv a_i \pmod{m_i}, \quad x_2 \equiv a_i \pmod{m_i}$$ 因此 $x_1 - x_2 \equiv 0 \pmod{m_i}$，即 $m_i \mid (x_1 - x_2)$。 由于 $m_1, m_2, \dots, m_k$ 两两互质，根据算术基本定理的推论， 有 $M \mid (x_1 - x_2)$，即 $x_1 \equiv x_2 \pmod{M}$。

第三步：存在性
上述构造方法给出了一个解，因此解存在。

$\square$

示例：解同余方程组

问题： 解同余方程组 $$ \begin{cases} x \equiv 2 \pmod{3} \\ x \equiv 3 \pmod{5} \\ x \equiv 2 \pmod{7} \end{cases} $$

解法：

  1. $m_1 = 3, m_2 = 5, m_3 = 7$，两两互质。
  2. $M = 3 \times 5 \times 7 = 105$
  3. $M_1 = 105 / 3 = 35$，$M_2 = 105 / 5 = 21$，$M_3 = 105 / 7 = 15$
  4. 求逆元：
    • $35 t_1 \equiv 1 \pmod{3}$ → $35 \equiv 2 \pmod{3}$，所以 $2t_1 \equiv 1 \pmod{3}$，得 $t_1 = 2$
    • $21 t_2 \equiv 1 \pmod{5}$ → $21 \equiv 1 \pmod{5}$，所以 $t_2 = 1$
    • $15 t_3 \equiv 1 \pmod{7}$ → $15 \equiv 1 \pmod{7}$，所以 $t_3 = 1$
  5. 构造解： $$ \begin{aligned} x &\equiv a_1 M_1 t_1 + a_2 M_2 t_2 + a_3 M_3 t_3 \pmod{105} \\ &\equiv 2 \times 35 \times 2 + 3 \times 21 \times 1 + 2 \times 15 \times 1 \pmod{105} \\ &\equiv 140 + 63 + 30 \pmod{105} \\ &\equiv 233 \pmod{105} \\ &\equiv 23 \pmod{105} \end{aligned} $$

验证：

  • $23 \div 3 = 7 \cdots 2$，所以 $23 \equiv 2 \pmod{3}$
  • $23 \div 5 = 4 \cdots 3$，所以 $23 \equiv 3 \pmod{5}$
  • $23 \div 7 = 3 \cdots 2$，所以 $23 \equiv 2 \pmod{7}$
符合所有方程。

代码示例 (C++)

算法复杂度： 设模数的个数为 $k$，最大模数为 $m_{\text{max}}$，则时间复杂度为 $O(k \log m_{\text{max}})$（主要开销在于求逆元的扩展欧几里得算法），空间复杂度为 $O(k)$（存储中间计算结果）。


#include <iostream>
#include <utility>
#include <vector>
using namespace std;

// 扩展欧几里得算法求逆元
long long modInverse(long long a, long long m) {
    long long old_r = a, r = m;
    long long old_s = 1, s = 0;
    while (r != 0) {
        long long quotient = old_r / r;
        long long tmp_r = old_r - quotient * r;
        old_r = r;
        r = tmp_r;
        long long tmp_s = old_s - quotient * s;
        old_s = s;
        s = tmp_s;
    }
    // 确保逆元是正数
    return (old_s % m + m) % m;
}

// 中国剩余定理实现
long long chineseRemainderTheorem(const vector<pair<long long, long long>>& congruences) {
    // congruences: (余数 a, 模数 m)
    // 计算 M = m1 * m2 * ... * mk
    long long M = 1;
    for (auto cong : congruences) {
        M *= cong.second;
    }

    long long solution = 0;
    for (auto cong : congruences) {
        long long a_i = cong.first;
        long long m_i = cong.second;
        long long M_i = M / m_i;

        // 求 M_i 在模 m_i 下的逆元
        long long t_i = modInverse(M_i, m_i);

        // 累加
        solution += a_i * M_i * t_i;
    }

    // 取模 M 得到最小非负解
    return ((solution % M) + M) % M;
}

int main() {
    // 示例使用
    vector<pair<long long, long long>> congruences = {
        {2, 3}, {3, 5}, {2, 7}
    };

    long long result = chineseRemainderTheorem(congruences);
    cout << "解为: x ≡ " << result << " (mod 105)\n";  // 输出: 解为: x ≡ 23 (mod 105)

    // 验证
    cout << "验证:\n";
    for (auto cong : congruences) {
        long long remainder = result % cong.second;
        cout << result << " ≡ " << remainder << " (mod " << cong.second
             << ")，要求 " << cong.first << "，"
             << (remainder == cong.first ? "✓" : "✗") << "\n";
    }

    // 更复杂的例子
    vector<pair<long long, long long>> example2 = {
        {1, 2}, {2, 3}, {3, 5}, {4, 7}
    };
    cout << "第二个例子解为: " << chineseRemainderTheorem(example2) << "\n";

    return 0;
}

应用：

  1. 大整数表示： 中国剩余定理可将大整数运算分解为多个小模数下的运算，提高计算效率。
  2. 密码学： 在RSA密码系统中，中国剩余定理被用于加速解密过程。
  3. 计算机代数： 用于多项式插值和多项式同余方程的求解。
  4. 历法计算： 历史上用于解决天文周期和历法推算问题。
  5. 错误检测与纠正： 在编码理论中，利用不同模数的同余关系检测和纠正数据传输中的错误。

📝 历史背景：

中国剩余定理最早出现在公元3-4世纪的中国数学著作《孙子算经》中， 提出了"物不知数"问题："今有物不知其数，三三数之剩二，五五数之剩三，七七数之剩二，问物几何？" 这就是中国剩余定理的经典例子。

该定理在秦九韶的《数书九章》（1247年）中得到了系统化的阐述。 在欧洲，类似的结果直到18世纪才由欧拉和高斯重新发现并证明。

注意： 定理要求模数两两互质。当模数不互质时，方程组可能有解也可能无解， 需要先将模数分解为互质的部分或使用其他方法。

推广：模数不互质的情况

当模数 $m_1, m_2, \dots, m_k$ 不一定两两互质时，方程组 $$ \begin{cases} x \equiv a_1 \pmod{m_1} \\ x \equiv a_2 \pmod{m_2} \\ \quad \vdots \end{cases} $$ 有解的充要条件是：对于所有 $i \neq j$，有 $$a_i \equiv a_j \pmod{\gcd(m_i, m_j)}$$

当有解时，解在模 $\operatorname{lcm}(m_1, m_2, \dots, m_k)$ 意义下唯一。
