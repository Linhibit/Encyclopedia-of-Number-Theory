费马二平方和定理 (Fermat's Two-Square Theorem)

定理内容：

一个奇素数 $p$ 可以表示为两个整数的平方和，即： $$p = a^2 + b^2 \quad (a, b \in \mathbb{Z})$$ 当且仅当 $p \equiv 1 \pmod{4}$。

等价表述：

  1. 奇素数 $p$ 可以表示为两个平方数之和当且仅当 $p = 2$ 或 $p \equiv 1 \pmod{4}$。
  2. 奇素数 $p$ 在整数环 $\mathbb{Z}[i]$（高斯整数环）中不是素元当且仅当 $p \equiv 1 \pmod{4}$。

例子：

  • $5 = 1^2 + 2^2$，且 $5 \equiv 1 \pmod{4}$ ✓
  • $13 = 2^2 + 3^2$，且 $13 \equiv 1 \pmod{4}$ ✓
  • $17 = 1^2 + 4^2$，且 $17 \equiv 1 \pmod{4}$ ✓
  • $3 = ?$，但 $3 \equiv 3 \pmod{4}$，不能表示为两个平方和 ✓
  • $7 = ?$，但 $7 \equiv 3 \pmod{4}$，不能表示为两个平方和 ✓

证明思路：

必要性证明（较简单）：

  1. 假设 $p = a^2 + b^2$，其中 $a, b$ 为整数。
  2. 平方数模4只能是0或1，所以 $a^2 + b^2$ 模4只能是0, 1, 2。
  3. 由于 $p$ 是奇素数，不能是偶数，所以 $a^2 + b^2 \equiv 1 \pmod{4}$。
  4. 因此 $p \equiv 1 \pmod{4}$ 是必要条件。

充分性证明（需要更多工具）：

  1. 若 $p \equiv 1 \pmod{4}$，则存在整数 $x$ 使得 $x^2 \equiv -1 \pmod{p}$。
  2. 考虑所有形如 $a + bx$ 的数，其中 $0 \le a, b \le \lfloor\sqrt{p}\rfloor$。
  3. 根据抽屉原理，存在两对不同的 $(a,b)$ 使得 $a + bx \equiv a' + b'x \pmod{p}$。
  4. 设 $u = a - a'$，$v = b - b'$，则 $u + vx \equiv 0 \pmod{p}$。
  5. 因此 $p \mid (u^2 + v^2)$，且 $0 < u^2 + v^2 < 2p$。
  6. 所以 $u^2 + v^2 = p$，即 $p$ 可以表示为两个平方和。

另一种证明（使用高斯整数）：

  1. 在 $\mathbb{Z}[i]$ 中，$p \mid (x^2 + 1) = (x + i)(x - i)$。
  2. 由于 $p \nmid (x \pm i)$，$p$ 不是 $\mathbb{Z}[i]$ 中的素元。
  3. 因此 $p = \alpha \beta$，其中 $\alpha, \beta \in \mathbb{Z}[i]$ 且不是单位。
  4. 取范数：$p^2 = N(p) = N(\alpha)N(\beta)$，所以 $N(\alpha) = N(\beta) = p$。
  5. 设 $\alpha = a + bi$，则 $N(\alpha) = a^2 + b^2 = p$。

示例与应用：

示例1： 找出 $p = 29$ 的二平方和表示。

解法：

  1. 首先验证 $29 \equiv 1 \pmod{4}$，所以存在表示。
  2. 尝试 $a = 1$：$29 - 1^2 = 28$，不是完全平方数。
  3. $a = 2$：$29 - 4 = 25$，是完全平方数 $5^2$。
  4. 所以 $29 = 2^2 + 5^2$。
  5. 另一种表示：$29 = 5^2 + 2^2$（相同）。

示例2： 判断 $p = 97$ 是否可以表示为二平方和。

解法：

  1. $97 \equiv 1 \pmod{4}$，所以可以表示。
  2. 寻找表示：$97 - 1^2 = 96$（不是平方），$97 - 4 = 93$（不是），$97 - 9 = 88$（不是）
  3. $97 - 16 = 81 = 9^2$，所以 $97 = 4^2 + 9^2$。

示例3： 合数的二平方和表示。

注意： 费马二平方和定理只适用于素数。对于合数：

  • $10 = 1^2 + 3^2$，但 $10 \equiv 2 \pmod{4}$
  • $25 = 0^2 + 5^2 = 3^2 + 4^2$，且 $25 \equiv 1 \pmod{4}$
  • 合数的二平方和表示有更复杂的规律，涉及素因子分解。

布拉马古普塔-斐波那契恒等式： $$(a^2 + b^2)(c^2 + d^2) = (ac + bd)^2 + (ad - bc)^2 = (ac - bd)^2 + (ad + bc)^2$$ 这个恒等式说明，两个可以表示为二平方和的数的乘积也可以表示为二平方和（且有两种方式）。

代码示例 (JavaScript)：

// 判断一个数是否为素数
function isPrime(n) {
    if (n <= 1) return false;
    if (n <= 3) return true;
    if (n % 2 === 0 || n % 3 === 0) return false;
    for (let i = 5; i * i <= n; i += 6) {
        if (n % i === 0 || n % (i + 2) === 0) return false;
    }
    return true;
}

// 使用费马二平方和定理判断素数是否可以表示为二平方和
function canBeRepresentedAsTwoSquares(p) {
    if (!isPrime(p)) {
        console.log(`注意：${p} 不是素数，费马二平方和定理只适用于素数`);
    }
    
    // 对于 p = 2，有 2 = 1^2 + 1^2
    if (p === 2) return true;
    
    // 奇素数可以表示为二平方和当且仅当 p ≡ 1 mod 4
    return (p % 4 === 1);
}

// 寻找二平方和表示（适用于满足条件的素数）
function findTwoSquaresRepresentation(p) {
    if (p === 2) return { a: 1, b: 1 };
    
    // 检查条件
    if (p % 4 !== 1) {
        return null; // 不能表示为二平方和
    }
    
    // 寻找 a 使得 p - a^2 是完全平方数
    for (let a = 1; a * a <= p; a++) {
        const remainder = p - a * a;
        const b = Math.sqrt(remainder);
        
        // 检查是否为整数平方
        if (Math.abs(b - Math.round(b)) < 1e-10) {
            return { a: a, b: Math.round(b) };
        }
    }
    
    return null; // 理论上不会执行到这里
}

// 使用更高效的算法（基于欧几里得算法）
function findTwoSquaresEfficient(p) {
    if (p === 2) return { a: 1, b: 1 };
    if (p % 4 !== 1) return null;
    
    // 步骤1：寻找 x 使得 x^2 ≡ -1 mod p
    let x = -1;
    for (let i = 2; i < p; i++) {
        if ((i * i) % p === p - 1) {
            x = i;
            break;
        }
    }
    
    // 步骤2：使用欧几里得算法
    let a = p;
    let b = x;
    
    while (b * b > p) {
        const r = a % b;
        a = b;
        b = r;
    }
    
    const b2 = Math.sqrt(p - b * b);
    if (Math.abs(b2 - Math.round(b2)) < 1e-10) {
        return { a: b, b: Math.round(b2) };
    }
    
    return null;
}

// 合数的二平方和表示
console.log("\n=== 合数的二平方和表示 ===");

function findTwoSquaresForComposite(n) {
    const representations = [];
    
    // 简单搜索（适用于较小的数）
    const limit = Math.sqrt(n);
    for (let a = 0; a <= limit; a++) {
        const a2 = a * a;
        const remainder = n - a2;
        if (remainder < 0) break;
        
        const b = Math.sqrt(remainder);
        if (Math.abs(b - Math.round(b)) < 1e-10) {
            representations.push({ a: a, b: Math.round(b) });
        }
    }
    
    return representations;
}

const compositeNumbers = [10, 25, 50, 65, 85, 100];
for (const n of compositeNumbers) {
    const reps = findTwoSquaresForComposite(n);
    console.log(`${n} 的二平方和表示:`);
    if (reps.length > 0) {
        reps.forEach(rep => {
            console.log(`  ${rep.a}² + ${rep.b}²`);
        });
    } else {
        console.log("  无（注意：有些数如6, 14等不能表示为二平方和）");
    }
}

// 判断素数在 Z[i] 中是否可约
function isPrimeInGaussianIntegers(p) {
    if (p === 2) return false; // 2 = (1+i)(1-i)，可约
    return (p % 4 === 1); // p ≡ 1 mod 4 时可约
}

for (const p of [2, 3, 5, 7, 11, 13, 17, 19]) {
    const reducible = isPrimeInGaussianIntegers(p);
    console.log(`${p} 在 Z[i] 中${reducible ? '可约' : '不可约（是素元）'}`);
}

应用与推广：

  1. 高斯整数环： 费马二平方和定理等价于在 $\mathbb{Z}[i]$ 中，奇素数 $p$ 是素元当且仅当 $p \equiv 3 \pmod{4}$。当 $p \equiv 1 \pmod{4}$ 时，$p$ 可以分解为两个高斯整数的乘积。
  2. 密码学： 在某些基于格的密码系统中，二平方和表示可以用于参数选择。
  3. 数论研究： 费马二平方和定理是研究平方和表示问题的起点，后来发展出更一般的定理（如四平方和定理）。
  4. 组合数学： 与分割和表示问题相关。
  5. 几何： 在圆上的整点问题中有应用。

📝 历史背景与扩展：

费马二平方和定理由皮埃尔·德·费马在1640年提出，但费马没有给出证明。欧拉在1747年给出了第一个完整的证明。

扩展： 1. 对于合数 $n$，可以表示为二平方和的充要条件是：$n$ 的每个形如 $4k+3$ 的素因子在 $n$ 的质因数分解中出现偶数次。
2. 若 $n$ 可以表示为二平方和，则 $n$ 的表示方法数 $r_2(n)$ 由雅可比公式给出： $$r_2(n) = 4(d_1(n) - d_3(n))$$ 其中 $d_1(n)$ 是 $n$ 的 $4k+1$ 型因子的个数，$d_3(n)$ 是 $n$ 的 $4k+3$ 型因子的个数。
3. 费马二平方和定理可以推广到其他二次型，如 $x^2 + 2y^2$、$x^2 + 3y^2$ 等。

注意： 费马二平方和定理是狄利克雷定理的一个特例，后者描述素数在算术级数中的分布。
