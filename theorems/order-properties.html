阶的性质定理 (Properties of Order)

阶的定义：

设 $n$ 为正整数，$a$ 为整数且 $\gcd(a, n) = 1$。 $a$ 模 $n$ 的阶定义为最小的正整数 $k$，使得： $$a^k \equiv 1 \pmod{n}$$ 记作 $\operatorname{ord}_n(a)$ 或 $\operatorname{ord}(a, n)$。

基本性质定理： 设 $\gcd(a, n) = 1$，$d = \operatorname{ord}_n(a)$，则：

  1. $a^m \equiv 1 \pmod{n}$ 当且仅当 $d \mid m$。
  2. $d \mid \varphi(n)$，其中 $\varphi$ 是欧拉函数。
  3. 若 $a^k \equiv a^l \pmod{n}$，则 $k \equiv l \pmod{d}$。
  4. $\operatorname{ord}_n(a^s) = \frac{d}{\gcd(d, s)}$，特别地，当 $\gcd(s, d) = 1$ 时，$\operatorname{ord}_n(a^s) = d$。
  5. 若 $\gcd(m, n) = 1$，则 $\operatorname{ord}_{mn}(a) = \operatorname{lcm}(\operatorname{ord}_m(a), \operatorname{ord}_n(a))$。

阶的详细性质：

1. 阶与整除关系

若 $\gcd(a, n) = 1$，$d = \operatorname{ord}_n(a)$，则对于任意正整数 $m$： $$a^m \equiv 1 \pmod{n} \iff d \mid m$$ 这是阶的最基本性质，表明 $d$ 是使得 $a^k \equiv 1 \pmod{n}$ 的所有正整数 $k$ 的最小公因子。

2. 阶的上界（欧拉定理推论）

由欧拉定理，$a^{\varphi(n)} \equiv 1 \pmod{n}$，所以： $$\operatorname{ord}_n(a) \mid \varphi(n)$$ 特别地，$\operatorname{ord}_n(a) \leq \varphi(n)$。当 $\operatorname{ord}_n(a) = \varphi(n)$ 时，$a$ 称为模 $n$ 的原根。

3. 幂的阶

设 $d = \operatorname{ord}_n(a)$，则对于任意正整数 $s$： $$\operatorname{ord}_n(a^s) = \frac{d}{\gcd(d, s)}$$ 推论：

  • 若 $\gcd(s, d) = 1$，则 $\operatorname{ord}_n(a^s) = d$。
  • 特别地，$\operatorname{ord}_n(a^{-1}) = \operatorname{ord}_n(a)$，其中 $a^{-1}$ 是 $a$ 模 $n$ 的逆元。

4. 不同模数下的阶

若 $\gcd(m, n) = 1$，则： $$\operatorname{ord}_{mn}(a) = \operatorname{lcm}\big(\operatorname{ord}_m(a), \operatorname{ord}_n(a)\big)$$ 这个性质允许我们将模数分解为互质的因子来计算阶。

5. 阶与循环子群

设 $\gcd(a, n) = 1$，$d = \operatorname{ord}_n(a)$，则集合： $$\langle a \rangle = \{a^0, a^1, a^2, \dots, a^{d-1}\} \pmod{n}$$ 构成模 $n$ 乘法群 $(\mathbb{Z}/n\mathbb{Z})^\times$ 的一个 $d$ 阶循环子群。

示例：

示例1： 求 $2$ 模 $7$ 的阶。

解法：

  1. 计算 $2^k \bmod 7$：
    • $2^1 \equiv 2 \pmod{7}$
    • $2^2 \equiv 4 \pmod{7}$
    • $2^3 \equiv 1 \pmod{7}$
  2. 所以 $\operatorname{ord}_7(2) = 3$。
  3. 验证性质：$\varphi(7) = 6$，$3 \mid 6$，符合性质2。

示例2： 已知 $\operatorname{ord}_{13}(2) = 12$（$2$ 是模 $13$ 的原根），求 $\operatorname{ord}_{13}(2^3)$。

解法： 使用性质3：$\operatorname{ord}_{13}(2^3) = \frac{12}{\gcd(12, 3)} = \frac{12}{3} = 4$。 验证：$2^3 = 8$，计算 $8^k \bmod 13$：

  • $8^1 \equiv 8 \pmod{13}$
  • $8^2 \equiv 64 \equiv 12 \pmod{13}$
  • $8^3 \equiv 8 \times 12 = 96 \equiv 5 \pmod{13}$
  • $8^4 \equiv 8 \times 5 = 40 \equiv 1 \pmod{13}$
确实 $\operatorname{ord}_{13}(8) = 4$。

示例3： 已知 $\operatorname{ord}_5(2) = 4$，$\operatorname{ord}_7(2) = 3$，求 $\operatorname{ord}_{35}(2)$。

解法： 使用性质4：因为 $\gcd(5, 7) = 1$， $$\operatorname{ord}_{35}(2) = \operatorname{lcm}(\operatorname{ord}_5(2), \operatorname{ord}_7(2)) = \operatorname{lcm}(4, 3) = 12$$ 验证：$\varphi(35) = \varphi(5)\varphi(7) = 4 \times 6 = 24$，$12 \mid 24$，符合性质2。

代码示例 (C++)


#include <iostream>
#include <vector>
#include <algorithm>
#include <utility>
using namespace std;

// 最大公约数
long long gcd_ll(long long a, long long b) {
    while (b) {
        long long t = a % b;
        a = b;
        b = t;
    }
    return a;
}

// 快速幂：计算 (base^exp) % mod
long long modPow(long long base, long long exp, long long mod) {
    if (mod == 1) return 0;
    long long result = 1 % mod;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}

// 计算欧拉函数
long long eulerPhi(long long n) {
    long long result = n;
    long long temp = n;
    for (long long p = 2; p * p <= temp; p++) {
        if (temp % p == 0) {
            while (temp % p == 0) temp /= p;
            result -= result / p;
        }
    }
    if (temp > 1) result -= result / temp;
    return result;
}

// 获取一个数的所有正因子
vector<long long> getDivisors(long long num) {
    vector<long long> divisors;
    for (long long i = 1; i * i <= num; i++) {
        if (num % i == 0) {
            divisors.push_back(i);
            if (i != num / i) divisors.push_back(num / i);
        }
    }
    sort(divisors.begin(), divisors.end());
    return divisors;
}

// 计算a模n的阶（直接方法）
long long orderDirect(long long a, long long n) {
    if (gcd_ll(a, n) != 1) {
        cerr << "a和n必须互质\n";
        return -1;
    }
    long long result = 1;
    long long power = a % n;
    while (power != 1) {
        power = power * a % n;
        result++;
        if (result > n * 2) {
            cerr << "计算阶时超出限制，可能出错\n";
            return -1;
        }
    }
    return result;
}

// 使用欧拉函数优化计算阶
long long orderUsingPhi(long long a, long long n) {
    if (gcd_ll(a, n) != 1) {
        cerr << "a和n必须互质\n";
        return -1;
    }
    long long phiN = eulerPhi(n);
    vector<long long> divisors = getDivisors(phiN);
    for (long long k : divisors) {
        if (modPow(a, k, n) == 1) return k;
    }
    return phiN;
}

// 验证阶的性质
void verifyOrderProperties(long long a, long long n) {
    if (gcd_ll(a, n) != 1) {
        cout << "a=" << a << "和n=" << n << "不互质\n";
        return;
    }
    long long d = orderDirect(a, n);
    long long phi = eulerPhi(n);

    cout << "\n=== 验证 a=" << a << " 模 n=" << n << " 的阶的性质 ==\n";
    cout << "ord_" << n << "(" << a << ") = " << d << "\n";
    cout << "φ(" << n << ") = " << phi << "\n";

    // 性质1：d整除任意满足a^m ≡ 1 mod n的m
    cout << "\n1. 验证性质1：d整除所有满足a^m ≡ 1 mod n的m\n";
    bool testPass1 = true;
    for (long long m = 1; m <= phi * 2; m++) {
        if (modPow(a, m, n) == 1) {
            if (m % d != 0) {
                cout << "  错误：a^" << m << " ≡ 1 mod " << n << "，但" << d << "不整除" << m << "\n";
                testPass1 = false;
            }
        }
    }
    if (testPass1) cout << "  性质1验证通过\n";

    // 性质2：d | φ(n)
    cout << "\n2. 验证性质2：d | φ(n)\n";
    if (phi % d == 0) {
        cout << "  " << d << " 整除 φ(" << n << ")=" << phi << "，商为" << phi / d << "\n";
    } else {
        cout << "  错误：" << d << " 不整除 φ(" << n << ")=" << phi << "\n";
    }

    // 性质3：幂的阶
    cout << "\n3. 验证性质3：ord(a^s) = d / gcd(d, s)\n";
    for (long long s = 1; s <= 10; s++) {
        long long expected = d / gcd_ll(d, s);
        long long actual = orderDirect(modPow(a, s, n), n);
        if (expected != actual) {
            cout << "  错误：ord(" << a << "^" << s << ")，期望=" << expected << "，实际=" << actual << "\n";
        }
    }
    cout << "  性质3验证通过（s=1..10）\n";

    // 性质4：原根的判定
    cout << "\n4. 原根判定：\n";
    if (d == phi) {
        cout << "  " << a << "是模" << n << "的原根（因为ord=" << d << "=φ(" << n << ")）\n";
    } else {
        cout << "  " << a << "不是模" << n << "的原根（因为ord=" << d << "≠φ(" << n << ")=" << phi << "）\n";
    }
}

int main() {
    cout << "=== 阶的性质验证 ===\n";

    verifyOrderProperties(2, 7);
    verifyOrderProperties(2, 13);
    verifyOrderProperties(3, 10);

    cout << "\n=== 计算不同数的阶 ===\n";
    vector<pair<long long, long long>> testCases = {
        {2, 7}, {3, 7}, {2, 9}, {5, 12}, {7, 15}
    };
    for (auto test : testCases) {
        long long a = test.first, n = test.second;
        if (gcd_ll(a, n) != 1) {
            cout << "ord_" << n << "(" << a << ")：a和n必须互质\n";
        } else {
            long long ord = orderDirect(a, n);
            long long phi = eulerPhi(n);
            cout << "ord_" << n << "(" << a << ") = " << ord << ", φ(" << n << ") = " << phi << ", "
                 << (ord == phi ? "是原根" : "不是原根") << "\n";
        }
    }

    cout << "\n=== 对比两种计算阶的方法 ===\n";
    long long a = 2, n = 17;
    long long ord1 = orderDirect(a, n);
    long long ord2 = orderUsingPhi(a, n);
    cout << "ord_" << n << "(" << a << ")：直接法=" << ord1 << "，欧拉函数法=" << ord2 << "，"
         << (ord1 == ord2 ? "一致" : "不一致") << "\n";

    cout << "\n=== 验证幂的阶的性质 ===\n";
    long long base = 2, mod = 11;
    long long baseOrder = orderDirect(base, mod);
    cout << "ord_" << mod << "(" << base << ") = " << baseOrder << "\n";
    for (long long s = 1; s <= baseOrder; s++) {
        long long power = modPow(base, s, mod);
        long long powerOrder = orderDirect(power, mod);
        long long expected = baseOrder / gcd_ll(baseOrder, s);
        cout << "ord_" << mod << "(" << base << "^" << s << "=" << power << ") = " << powerOrder
             << "，期望=" << expected << "，" << (powerOrder == expected ? "✓" : "✗") << "\n";
    }

    return 0;
}

应用：

  1. 原根判定： 通过计算阶可以判断一个数是否是模 $n$ 的原根：$a$ 是模 $n$ 的原根当且仅当 $\operatorname{ord}_n(a) = \varphi(n)$。
  2. 离散对数问题： 在密码学中，基于离散对数的密码系统（如Diffie-Hellman、ElGamal）依赖于阶的性质。
  3. 素性测试： 某些素性测试算法（如Pocklington定理）需要计算阶。
  4. 循环群结构： 阶的性质揭示了模 $n$ 乘法群的结构。
  5. 指数同余方程： 求解形如 $a^x \equiv b \pmod{n}$ 的方程需要理解阶的性质。

相关定理：

  1. 拉格朗日定理（群论）： 有限子群的阶整除群的阶。在数论中，这表现为 $\operatorname{ord}_n(a) \mid \varphi(n)$。
  2. 费马小定理： 若 $p$ 是素数，$\gcd(a, p) = 1$，则 $a^{p-1} \equiv 1 \pmod{p}$， 因此 $\operatorname{ord}_p(a) \mid (p-1)$。
  3. 欧拉定理： 若 $\gcd(a, n) = 1$，则 $a^{\varphi(n)} \equiv 1 \pmod{n}$， 因此 $\operatorname{ord}_n(a) \mid \varphi(n)$。
  4. 原根存在定理： 模 $n$ 有原根当且仅当 $n = 1, 2, 4, p^k, 2p^k$（$p$ 为奇素数）。

📝 重要结论：

1. 阶是循环子群的大小，反映了元素 $a$ 在模 $n$ 乘法群中的"周期"。
2. 计算 $\operatorname{ord}_n(a)$ 的有效方法是：先计算 $\varphi(n)$，然后找出 $\varphi(n)$ 的所有因子 $d$， 检查 $a^d \equiv 1 \pmod{n}$ 的最小 $d$。
3. 当 $n$ 是素数 $p$ 时，阶一定是 $p-1$ 的因子。
4. 如果 $\operatorname{ord}_n(a) = \varphi(n)$，则 $a$ 是模 $n$ 的原根，此时 $\{a^0, a^1, \dots, a^{\varphi(n)-1}\}$ 构成模 $n$ 的简化剩余系。
