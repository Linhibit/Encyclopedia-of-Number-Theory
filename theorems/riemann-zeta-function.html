黎曼ζ函数 (Riemann Zeta Function)

定义：

对于复数 $s$，满足 $\operatorname{Re}(s) \gt 1$ 时，黎曼 $\zeta$ 函数定义为： $$\zeta(s) = \sum_{n=1}^\infty \frac{1}{n^s}$$ 通过解析延拓，$\zeta(s)$ 可以延拓为整个复平面上的亚纯函数，仅在 $s = 1$ 处有一个单极点，留数为 $1$。

重要性质：

  1. 欧拉乘积公式（当 $\operatorname{Re}(s) \gt 1$ 时）： $$\zeta(s) = \prod_{p \text{ prime}} \frac{1}{1 - p^{-s}}$$ 这一公式揭示了 $\zeta$ 函数与素数分布的深刻联系。
  2. 函数方程： $$\zeta(s) = 2^s \pi^{s-1} \sin\left(\frac{\pi s}{2}\right) \Gamma(1-s) \zeta(1-s)$$ 其中 $\Gamma$ 是伽马函数。函数方程建立了 $\zeta(s)$ 与 $\zeta(1-s)$ 之间的关系。
  3. 平凡零点：$\zeta(s)$ 在负偶数 $s = -2, -4, -6, \dots$ 处有零点，称为平凡零点。
  4. 非平凡零点：除了平凡零点外，其余零点称为非平凡零点。黎曼猜想断言所有非平凡零点都位于直线 $\operatorname{Re}(s) = \frac{1}{2}$ 上。

解析延拓的简要思路：

方法一（黎曼本人给出的）：

  1. 考虑 $\Gamma$ 函数：$\Gamma(s) = \int_0^\infty x^{s-1} e^{-x} dx$，当 $\operatorname{Re}(s) \gt 0$ 时收敛。
  2. 将 $\zeta(s)$ 写成积分形式： $$\zeta(s) = \frac{1}{\Gamma(s)} \int_0^\infty \frac{x^{s-1}}{e^x - 1} dx \quad (\operatorname{Re}(s) \gt 1)$$
  3. 将积分路径分成 $[0, \infty)$ 和围道积分，利用复变函数理论得到延拓。

方法二（更初等的）：

  1. 定义 Dirichlet $\eta$ 函数（交替级数）： $$\eta(s) = \sum_{n=1}^\infty \frac{(-1)^{n-1}}{n^s} \quad (\operatorname{Re}(s) \gt 0)$$
  2. 利用关系 $\eta(s) = (1 - 2^{1-s}) \zeta(s)$，得到 $$\zeta(s) = \frac{1}{1 - 2^{1-s}} \eta(s)$$
  3. 由于 $\eta(s)$ 在 $\operatorname{Re}(s) \gt 0$ 时收敛，且 $1 - 2^{1-s}$ 在 $s=1$ 处有一阶零点，而 $\eta(1) = \log 2$，因此 $\zeta(s)$ 在 $s=1$ 处有单极点。

特殊值：

正整数点：

  • $\zeta(2) = \frac{\pi^2}{6}$（巴塞尔问题）
  • $\zeta(4) = \frac{\pi^4}{90}$
  • $\zeta(6) = \frac{\pi^6}{945}$
  • 一般地，对于正整数 $2n$，$\zeta(2n) = (-1)^{n+1} \frac{B_{2n} (2\pi)^{2n}}{2(2n)!}$，其中 $B_{2n}$ 是伯努利数。
  • $\zeta(3)$ 是阿培里常数，是无理数（已被证明）。

负整数点（由函数方程得到）：

  • $\zeta(0) = -\frac{1}{2}$
  • $\zeta(-1) = -\frac{1}{12}$（在弦理论中有时会用到）
  • $\zeta(-2) = 0$（平凡零点）
  • $\zeta(-3) = \frac{1}{120}$

其他重要值：

  • $\zeta(1)$ 发散（调和级数），但 $\zeta(s)$ 在 $s=1$ 处的洛朗展开为： $$\zeta(s) = \frac{1}{s-1} + \gamma + O(s-1)$$ 其中 $\gamma$ 是欧拉常数。
  • $\zeta\left(\frac{1}{2}\right) \approx -1.4603545088$（负值）

代码示例 (C++)

由于黎曼 $\zeta$ 函数是复变函数，这里我们仅计算实数部分 $s$ 的近似值（使用级数求和和加速技巧）。


#include <iostream>
#include <cmath>
using namespace std;

const double PI = acos(-1.0);

// 计算黎曼ζ函数在实数 s 上的近似值（s ≠ 1）
double riemannZeta(double s, int maxTerms = 1000000) {
    // 处理负整数（平凡零点）
    if (fmod(s, 2.0) == 0.0 && s <= 0.0) {
        return 0.0;
    }

    // 对于 s > 1，直接求和
    if (s > 1.0) {
        double sum = 0.0;
        for (int n = 1; n <= maxTerms; n++) {
            sum += pow((double)n, -s);
        }
        return sum;
    }

    // 对于 s < 1（包括 0 < s < 1 与 s < 0），使用狄利克雷η函数变换：
    // ζ(s) = η(s) / (1 - 2^(1-s))，其中 η(s) = Σ_{n=1}^∞ (-1)^(n-1) / n^s
    double eta = 0.0;
    // 交替级数收敛可能较慢，这里通过计算足够多的项来近似
    for (int n = 1; n <= maxTerms; n++) {
        double term = pow((double)n, -s);
        if (n % 2 == 0) {
            eta -= term;
        } else {
            eta += term;
        }
    }
    return eta / (1.0 - pow(2.0, 1.0 - s));
}

// Lanczos 近似计算 Γ 函数（简化版）
double gammaLanczos(double z) {
    // 系数
    const int g = 7;
    const double p[9] = {
        0.99999999999980993,
        676.5203681218851,
        -1259.1392167224028,
        771.32342877765313,
        -176.61502916214059,
        12.507343278686905,
        -0.13857109526572012,
        9.9843695780195716e-6,
        1.5056327351493116e-7
    };

    // 反射公式：对于 z < 0.5，使用 Γ(z) = π / (sin(πz) * Γ(1-z))
    if (z < 0.5) {
        return PI / (sin(PI * z) * gammaLanczos(1.0 - z));
    }

    z -= 1.0;
    double x = p[0];
    for (int i = 1; i < 9; i++) {
        x += p[i] / (z + i);
    }
    double t = z + g + 0.5;
    return sqrt(2.0 * PI) * pow(t, z + 0.5) * exp(-t) * x;
}

// 使用函数方程计算任意实数 s 的ζ函数值（近似）
double zeta(double s) {
    // 处理特殊情况
    if (s == 1.0) return INFINITY;                        // 调和级数发散
    if (s == 0.0) return -0.5;
    if (s < 0.0 && fmod(s, 2.0) == 0.0) return 0.0;       // 负偶数为平凡零点

    // 对于 s > 1，直接求和
    if (s > 1.0) {
        return riemannZeta(s);
    }

    // 对于 s < 0，使用函数方程：ζ(s) = 2^s * π^(s-1) * sin(πs/2) * Γ(1-s) * ζ(1-s)
    // 将 s 转换到 1 - s > 1 的区间，并使用 Lanczos 近似计算 Γ(1-s)
    if (s < 0.0) {
        double zeta1minusS = zeta(1.0 - s);      // 递归调用，此时 1 - s > 1
        double sinFactor = sin(PI * s / 2.0);
        double factor = pow(2.0, s) * pow(PI, s - 1.0);
        double gamma = gammaLanczos(1.0 - s);
        return factor * sinFactor * gamma * zeta1minusS;
    }

    // 对于 0 < s < 1，使用η函数变换
    return riemannZeta(s);
}

int main() {
    cout << "=== 黎曼ζ函数近似计算 ===\n";

    // 计算一些特殊值
    cout << "ζ(2) = " << zeta(2.0) << "，理论值 π²/6 ≈ " << (PI * PI / 6.0) << '\n';
    cout << "ζ(4) = " << zeta(4.0) << "，理论值 π⁴/90 ≈ " << (pow(PI, 4.0) / 90.0) << '\n';
    cout << "ζ(0) = " << zeta(0.0) << "，理论值 -1/2 = -0.5\n";
    cout << "ζ(-1) = " << zeta(-1.0) << "，理论值 -1/12 ≈ -0.0833333\n";
    cout << "ζ(-2) = " << zeta(-2.0) << "，理论值 0\n";

    // 计算非整数点
    cout << "ζ(0.5) = " << zeta(0.5) << "，近似值 -1.4603545\n";
    cout << "ζ(3) = " << zeta(3.0) << "，阿培里常数 ≈ 1.2020569\n";

    // 注意：由于级数收敛速度问题，对于 s < 1 的近似可能不准确，需要更多项或加速技巧。
    // 上述代码仅为演示，实际应用中应使用更专业的数学库。
    return 0;
}

应用：

  1. 素数定理： 黎曼 $\zeta$ 函数的非平凡零点分布与素数分布密切相关。素数定理 $\pi(x) \sim \frac{x}{\log x}$ 的证明依赖于 $\zeta$ 函数的非零区域。
  2. 解析数论： 许多数论问题（如哥德巴赫猜想、孪生素数猜想）的研究中，$\zeta$ 函数是重要工具。
  3. 物理学： 在量子场论、弦理论、统计力学中，$\zeta$ 函数正则化被用于处理发散级数。
  4. 概率论： 在某些随机过程的研究中也会出现 $\zeta$ 函数。

📝 黎曼猜想：

黎曼猜想是数学中最重要的未解决问题之一。它断言 $\zeta$ 函数的所有非平凡零点都位于复平面上的直线 $\Re(s) = \frac{1}{2}$ 上。

黎曼猜想如果成立，将极大地改进素数分布的误差估计，并对数论和许多数学分支产生深远影响。

注意： 黎曼 $\zeta$ 函数是解析数论的核心对象，其研究涉及复分析、调和分析、代数几何等多个领域。
